This chapter builds the language of functions: how to describe mappings, test whether they have inverses, and combine them. It then applies that language to polynomials, trigonometric and exponential functions, and polar coordinates.

3.1 The Graph of a Mapping

A function is more than a formula: its domain and codomain are part of its definition. This lets you ask exactly which outputs occur and which inputs lead to a chosen set of outputs.

In plain words: think of a mapping as a machine with an input tray X and an output tray Y. Every input you drop in comes out as exactly one output. Two inputs may come out the same, and some outputs may never appear at all. The outputs that do appear form the image; the inputs whose output lands in a chosen set B form the preimage of B.

Mapping and imagef:X→YIm(f) = {f(x):x∈X}⊆YRead it as: “f maps X to Y”, and “the image of f is the set of all f(x) as x runs through X; it lies inside Y”.X is the domain; Y is the codomain; Im(f) is the image or range. Every x∈X must be assigned exactly one value f(x)∈Y.
Image, preimage and graphf(A) = {f(x):x∈A}f−1(B) = {x∈X:f(x)∈B}Gr(f) = {(x,y)∈X×Y:y = f(x)}Read it as: “f of A is the set of outputs of the inputs in A”; “the preimage of B is the set of x in X whose output lies in B”; “the graph of f is the set of pairs (x, y) in X × Y with y = f(x)”.A⊆X and B⊆Y. Preimage notation f−1(B) is defined even when f has no inverse function.

A real-valued function has a graph in the coordinate plane. Each vertical line must meet the graph at most once: two y-values for one x would violate the mapping rule. A horizontal line may meet it more than once; that tells you the function is not injective, not that it fails to be a function.

A rule need not be a single formula. The absolute value |x| splits into cases, and the Dirichlet function on [0,1] takes the value 1 at rational x and 0 at irrational x: it is a perfectly good mapping even though its graph cannot be drawn. A real-world assignment counts too, provided every input gets exactly one output, for example each product on a supermarket shelf gets exactly one price.

Worked example · image and preimage

Let f:ℝ→ℝ be f(x)=x2, and let A={−2,0,3}, B={4}.

  1. Apply the rule to each member of A: f(A)={4,0,9}.
  2. To find f−1(B), solve x2=4 over the stated domain ℝ. Both x=−2 and x=2 work, so f−1({4})={−2,2}.
  3. The image is [0,∞), which is smaller than the codomain ℝ. Check: a square cannot be negative.

Trap: f−1(B) means “inputs that land in B”; it does not mean “apply the inverse function”. The inverse function exists only if f is injective.

Near miss: the rule “x ↦ ±√x” on [0, ∞) looks like a function, but it sends 4 to both 2 and −2. Two outputs for one input break the mapping rule; keeping only the positive root, x ↦ √x, makes it a mapping.

Try it: map inputs and compare image with codomain.

Recall check · answer before opening

  2. Can a preimage be defined when f is not injective?
Show answers
  1. The domain X, codomain Y, and image Im(f)⊆Y. §3.1
  2. Yes. f−1(B) is the set of domain inputs whose outputs lie in B, whether or not f has an inverse function. §3.1

3.2 Types of Mappings

Injectivity and surjectivity answer different questions. Together they determine whether every output has exactly one input.

In plain words: picture the arrows from X to Y. Injective means no point of Y receives two arrows: different inputs never share an output. Surjective means every point of Y receives at least one arrow: nothing in the codomain is left out. Bijective means both, so inputs and outputs pair up one to one.

Injectivex1 ≠ x2 ⇒ f(x1) ≠ f(x2)Read it as: “if x1 is not x2, then f(x1) is not f(x2)”: different inputs always give different outputs.Distinct inputs have distinct outputs; equivalently, f(x1)=f(x2) implies x1=x2.
Surjective and bijectivef is onto Y iff Im(f) = Ybijective iff injective and surjectiveRead it as: “f is onto Y if and only if its image is all of Y”, and “bijective means injective and surjective at once”.Surjectivity depends on the chosen codomain. A function is always surjective when its codomain is restricted to its image. Injectivity, in contrast, depends only on the graph {(x,f(x)):x∈X}: changing the codomain never changes it.

For f:ℝ→ℝ, f(x)=x3 is strictly increasing and reaches every real value, so it is bijective. In contrast, x2 maps 1 and −1 to the same output and never reaches negative values: it is neither injective nor surjective onto ℝ. Restricting it to f:[0,∞)→[0,∞) makes it bijective.

Worked example · the codomain changes surjectivity

Consider f(x)=x2 with domain [0,∞).

  1. If the codomain is ℝ, the mapping is injective but not surjective, because no negative real is a square.
  2. If the codomain is [0,∞), every codomain value y has the preimage √y. Thus it is surjective too.
  3. So f:[0,∞)→[0,∞) is bijective. Check: each y≥0 has exactly one non-negative square root.

Memory hook: injective asks “does any output have two inputs?”; surjective asks “does any codomain value have no input?”. State the codomain before answering.

Near miss: f(x) = x2 on [−1, ∞) is almost injective. On [0, ∞) it is, but −1 and 1 both give 1, and one shared output is enough to fail.

Try it: test injectivity and surjectivity.

Recall check · answer before opening

  1. What is the difference between injective and surjective?
  2. Why is x↦x2 not onto ℝ?
Show answers
  1. Injective prevents two distinct inputs sharing an output; surjective requires every codomain value to occur. §3.2
  2. Its outputs are non-negative, so negative real numbers in the codomain have no preimage. §3.2

3.3 Inverse Function

An inverse undoes a mapping. It can do that consistently only when an output identifies one input.

In plain words: the inverse runs the machine backwards: hand it an output and it returns the one input that produced it. That is only possible when no output came from two inputs (the mapping is injective), and it only accepts outputs that actually occur, which is why its domain is the image.

Inverse functionf:X→Y injective ⇒ f−1:Im(f)→XRead it as: “if f from X to Y is injective, then f inverse goes from the image of f back to X”.For y∈Im(f), f−1(y) is the unique x∈X satisfying f(x)=y. The inverse domain is Im(f), not necessarily all of Y.
Inverse identitiesf−1∘f = idXf∘f−1 = idIm(f)Read it as: “f inverse after f is the identity on X”: doing f and then undoing it gives back every x. “f after f inverse is the identity on the image of f.”The domain and image switch. For real-valued functions, the two graphs reflect across y=x.

To find an inverse, write y=f(x), solve for x, then rename the output variable. Keep the domain restrictions: the inverse is defined only for values in the original image. Check both compositions when the domains allow it.

Worked example · solve for the inverse

Let f:ℝ→ℝ, f(x)=2x+3.

  1. Set y=2x+3 and solve: x=(y−3)/2.
  2. Therefore f−1(y)=(y−3)/2, with domain ℝ.
  3. Check: f−1(f(x))=((2x+3)−3)/2=x. Also f(f−1(y))=2((y−3)/2)+3=y.

Trap: f−1(x) is not 1/f(x). It means the inverse mapping. If f is not injective, solving y=f(x) may give multiple x-values and no inverse function.

Near miss: f(x) = x2 on ℝ cannot be inverted: 2 and −2 both give 4, so “the input that gave 4” is not unique. Restrict the domain to [0, ∞) and it becomes injective, with f−1(y) = √y.

Try it: restrict a function and reverse it.

Recall check · answer before opening

  1. What is the domain of f−1?
  2. How can you check a proposed inverse?
Show answers
  1. The image Im(f) of the original mapping. §3.3
  2. Compose in both directions on their stated domains and check that each composition is the identity. §3.3

3.4 Composition

Composition chains mappings. The output of the first mapping must be a valid input to the next.

In plain words: composition is running one machine after another: f first, then g on whatever f produced. The notation g ∘ f is read from right to left, exactly like g(f(x)). It only works if every output of f is something g accepts.

CompositionIf f:X→Y, g:D(g)⊆Y→Z, and Im(f)⊆D(g), then (g∘f)(x) = g(f(x))Read it as: “g after f, applied to x, equals g of f of x”. The function written next to x acts first.Read right to left: apply f first, then g. The containment condition guarantees the second step is defined for every first-step output.
Composition lawsh∘(g∘f) = (h∘g)∘fin general g∘f ≠ f∘gRead it as: “h after (g after f) equals (h after g) after f”, but “g after f is in general not f after g”.Composition is associative when the domains fit, but order usually matters. For a bijection, f−1∘f=idX.

Worked example · order and domain

Let f:ℝ→ℝ be f(x)=2x+1 and g:ℝ→ℝ be g(x)=x2.

  1. For g∘f, apply f then square: (g∘f)(x)=(2x+1)2.
  2. For f∘g, square then apply f: (f∘g)(x)=2x2+1.
  3. At x=1 these give 9 and 3, so the two compositions differ. This numerical check catches a reversed order.

Trap: do not apply the left-hand function first. Write the nested expression g(f(x)) before simplifying, and check that f’s image lies in g’s domain.

Near miss: with f(x) = x − 2 and g(x) = √x, the composite g(f(x)) = √(x − 2) is not defined on all of ℝ: f(0) = −2 lies outside the domain [0, ∞) of g. Restrict f to [2, ∞) first.

Try it: follow composition order and domain.

Recall check · answer before opening

  1. In g∘f, which mapping acts first?
  2. What must be true for g∘f to be defined on all of X?
Show answers
  1. f acts first, then g. §3.4
  2. Every output of f must lie in the domain of g: Im(f)⊆D(g). §3.4

3.5 Elementary Functions

This section collects important real-valued mappings. Their domain and range determine where inverse functions and formulas make sense.

In plain words: this section is a toolbox of the standard functions you will use all year: polynomials, the trigonometric functions, and the exponential and logarithm. For each one, learn three facts: where it is defined, which values it takes, and where it is injective. The last fact decides where it has an inverse: the logarithm undoes the exponential, and arcsin undoes sin on [−π/2, π/2].

Real polynomials

Polynomial and rootsP(x) = anxn + … + a1x + a0, an ≠ 0P(x0) = 0 means x0 is a rootRead it as: “P of x is a sum of powers of x, from an x to the n down to the constant a0, with an not zero”.The degree is n and the domain is ℝ. A degree-n polynomial has at most n real roots.
Quadratic formula and discriminantΔ = b2−4acx = (−b±√Δ)/(2a), ax2+bx+c = 0, a ≠ 0Read it as: “delta is b squared minus four a c”: its sign tells you how many real roots there are before you solve anything.Δ>0 gives two distinct real roots; Δ=0 gives one repeated root; Δ<0 gives no real roots. When Δ≥0, the roots factor the polynomial as a(x−x1)(x−x2).

Completing the square reveals why Δ controls the roots. Multiply the equation by 4a, add b2, and rewrite the left side as (2ax+b)2. Taking square roots creates a real solution only if Δ≥0.

Worked example · solve a quadratic

Solve x2−5x+6=0.

  1. Here a=1, b=−5, c=6, so Δ=(−5)2−4·1·6=1.
  2. The roots are (5±1)/2, hence x=2 or x=3.
  3. Check by factoring: x2−5x+6=(x−2)(x−3). Substitution gives zero at both roots.

General root formulas exist for degrees 3 and 4. For degree 5 and above there is no general formula built from the coefficients using only +, −, ×, ÷ and roots (the Abel–Ruffini theorem); the notes say “no general formulas”, which is meant in this sense. This does not prevent a particular higher-degree polynomial from factoring or having roots found by another method.

Sign check: for Δ<0 there are no real roots, but the polynomial still has a real graph. “No real roots” does not mean “no roots in every number system.”

Near miss: x2 + 1 = 0 looks as if it should have the roots ±1, but Δ = 0 − 4 = −4 < 0, so it has no real roots. It is x2 − 1 = 0, with Δ = 4, that has the roots ±1.

Trigonometric functions

Unit circle and radiansP = (cos x,sin x)tan x = sin x/cos xAngles are in radians. One full turn is 2π radians = 360°. On a right triangle, sin x is opposite/hypotenuse and cos x is adjacent/hypotenuse for acute x.
Degrees0°30°45°60°90°180°360°
Radians0π/6π/4π/3π/2π2π
Core trigonometric identitiessin(−x) = −sin xcos(−x) = cos xsin2x+cos2x = 1sin(x±y) = sin x cos y±cos x sin ycos(x±y) = cos x cos y∓sin x sin ysin and cos have period 2π. Their zeros are sin x=0 at x=kπ and cos x=0 at x=π/2+kπ, k∈ℤ.
Shifts and periodicitysin(x+π/2) = cos xcos(x+π/2) = −sin xsin(x+π) = −sin xcos(x+π) = −cos xsin(x+2π) = sin xcos(x+2π) = cos xEach follows from an addition formula with cos and sin of π/2, π or 2π. A quarter turn turns sine into cosine; a half turn flips both signs.
Double-angle and square identitiessin(2x) = 2 sin x cos xcos(2x) = 1−2 sin2x = 2 cos2x−1 = cos2x−sin2xsin2x = (1−cos 2x)/2cos2x = (1+cos 2x)/2These follow from the addition formulas and sin2x+cos2x=1.
Difference-to-product identitiessin x−sin y = 2 cos((x+y)/2) sin((x−y)/2)cos x−cos y = 2 sin((x+y)/2) sin((y−x)/2)The second factor uses (y−x)/2; reversing its sign would reverse the whole result.

Worked example · use an addition formula

Find sin(π/3+π/6).

  1. Use sin(x+y)=sin x cos y+cos x sin y.
  2. Substitute the special-angle values: (√3/2)(√3/2)+(1/2)(1/2)=3/4+1/4=1.
  3. The result matches sin(π/2)=1, a useful unit-circle check.

For inverse functions, restrict sine to [−π/2,π/2], cosine to [0,π], and tangent to (−π/2,π/2). Then arcsin and arccos have domain [−1,1], while arctan has domain ℝ. tan x is undefined when cos x=0, that is x=π/2+kπ.

Tangent identitiestan(−x) = −tan xtan(x±y) = (tan x±tan y)/(1∓tan x tan y)tan(2x) = 2 tan x/(1−tan2x)Use only where each tangent and denominator is defined. These follow by dividing the sine and cosine addition formulas.

Trap: inverse trigonometric functions return principal angles, not every angle with that sine or cosine. Check the interval and quadrant before giving a general solution.

Exponential and logarithmic functions

Exponential and natural logarithmex+y = exeyln(ex) = xeln y = y for y > 0ln(xy) = ln x+ln y for x,y > 0ln 1 = 0ex is strictly increasing, positive, and has range (0,∞). ln is its inverse, with domain (0,∞).
Base a and real powersax = ex ln a (a > 0)logax = ln x/ln a (a > 0, a ≠ 1, x > 0)xα = eα ln x for x > 0, α∈ℝFor 0<a<1, ax decreases; for a>1 it increases. The notes define arbitrary real powers xα only for positive x.

Worked example · solve an exponential equation

Solve 5x=125.

  1. Write 125=53, so 5x=53.
  2. Because the base 5 is positive and not 1, the exponential is injective. Therefore x=3.
  3. Check: 53=125 and x is allowed in the domain ℝ.

Trap: ln x is defined for x>0 only. Also, loga requires a>0 and a≠1; a=1 would give a constant function with no inverse.

Try it: inspect elementary function graphs.

  3. What are the domain and range of ln?

  2. [−π/2,π/2], where sine is one-to-one and has range [−1,1]. §3.5
  3. Its domain is (0,∞) and its range is ℝ. §3.5

3.6 Polar Coordinates

Cartesian coordinates locate a point by horizontal and vertical displacement. Polar coordinates use distance from the origin and angle from the positive x-axis.

In plain words: polar coordinates describe a point the way you give directions: how far to walk from the origin (r) and in which direction (the angle φ, measured from the positive x-axis). Cartesian coordinates say how far right and how far up. A right triangle with hypotenuse r links the two.

Polar to Cartesianx = r cos φy = r sin φRead it as: “x is r cos phi, y is r sin phi”: the horizontal and vertical sides of a right triangle with hypotenuse r and angle φ.Here r≥0 and φ is measured in radians from the positive x-axis. The point is (x,y)=(r cos φ,r sin φ).
Cartesian to polarr = √(x2+y2)tan φ = y/x when x ≠ 0Read it as: “r is the square root of x squared plus y squared” (Pythagoras), and “tan phi is y over x”, which fixes φ only up to the quadrant.Use the signs of x and y to select the quadrant. For 0≤φ<2π: use arctan(y/x) when x>0,y≥0; add 2π when x>0,y<0; add π when x<0; take π/2 when x=0,y>0 and 3π/2 when x=0,y<0. The origin has r=0 and no unique angle.

With r≥0 and unrestricted angle, polar coordinates are not unique: adding 2π does not move the point, and the origin has every angle. Restricting to r>0 and 0≤φ<2π gives one polar pair for every non-origin point. The origin must be handled separately if it is included.

Worked example · convert a point and a region

  1. Convert (x,y)=(−1,1). The radius is r=√(1+1)=√2. The point is in quadrant II, so φ=3π/4. Thus (−1,1)=(√2,3π/4).
  2. Convert the region 0≤r≤2, 0≤φ≤π/4. Since r2=x2+y2, it lies inside the circle x2+y2≤4. The angle range is the first-quadrant wedge between y=0 and y=x, so 0≤y≤x.
  3. Check a boundary point: r=2, φ=π/4 gives x=y=√2 and x2+y2=4.

Sign check: arctan(y/x) alone returns an angle only in its principal range. Use the signs of both coordinates; when x=0, use the vertical-axis cases, and at the origin the angle is undefined.

Near miss: for (x, y) = (−1, −1), tan φ = 1 suggests φ = π/4, but that points into the first quadrant. Both coordinates are negative, so add π: φ = 5π/4.

Try it: rotate a radius into Cartesian components.

Recall check · answer before opening

  1. What are x and y in terms of r and φ?
  2. Why must you check the quadrant when finding φ?
Show answers
  1. x=r cos φ and y=r sin φ. §3.6
  2. Because arctan(y/x) alone cannot distinguish opposite quadrants and division by x fails when x=0. §3.6

  4. When is g∘f defined for every x in X?
  5. Why does the discriminant determine the number of real quadratic roots?
  6. Why must inverse trigonometric functions use restricted intervals?
  7. When is loga x defined, and why can a not equal 1?
  8. Why do polar coordinates need a chosen angle interval?
Show model answers
  1. The codomain specifies which outputs count as possible and therefore determines whether the mapping is onto. The same rule can be surjective for one codomain and not another.
  2. When the new codomain is the image of the mapping. Every image value is reached by definition.
  3. If two inputs share one output, reversing that output would require choosing between them. Injectivity makes the input unique.
  4. When every output of f lies in the domain of g, so Im(f)⊆D(g).
  5. Completing the square yields (2ax+b)2=Δ. A real square root exists only for Δ≥0; positive Δ gives two signs, zero gives one repeated value.
  6. Sine, cosine and tangent repeat values, so they are not one-to-one on their full domains. Restricting to a principal interval makes each inverse return one defined angle.
  7. x must be positive, and a must be positive but not 1. Otherwise ln x is not real, or at is not invertible because it is constant at 1.
  8. Without a restriction, angles differing by 2π describe the same point. The origin has no unique angle even after an interval is selected.

Allow about 20 minutes for each. Work every part before checking the answer. Afterward, note where you lost a step and revisit the cited sections.

1 · Inverses, image and composition

Let f:[0,∞)→[0,∞), f(x)=x2, and g:[0,∞)→ℝ, g(t)=t−1.

  1. State whether f is injective and surjective, with reasons.
  2. Find f−1 and verify one inverse composition.
  3. Find g∘f, its image, and its domain.
  4. Is f∘g defined on all of g’s domain? Explain.
Show the worked answer
  1. f is strictly increasing on [0,∞), so it is injective. Every y≥0 is f(√y), so it is onto [0,∞) and bijective. §3.2
  2. Solving y=x² with x≥0 gives f−1(y)=√y. Then f−1(f(x))=√(x²)=x for x≥0. §3.3
  3. (g∘f)(x)=x²−1; its domain is [0,∞) and its image is [−1,∞). §3.1 §3.4
  4. No. g outputs [−1,∞), but f accepts only non-negative inputs. For t∈[0,1), g(t)=t−1 is negative, so f(g(t))=f(t−1) is undefined. §3.4

2 · Quadratic, trigonometric and polar tools

Consider P(x)=x²−2x−3 and the point with polar coordinates (r,φ)=(4,π/3).

  1. Use the discriminant to find and classify the roots of P.
  2. Write P in factored form and verify one root.
  3. Convert (r,φ) to Cartesian coordinates.
  4. Find sin(5π/12) exactly by writing 5π/12=π/4+π/6, and explain why the size of the result is consistent with the unit circle.
Show the worked answer
  1. Δ=(−2)²−4·1·(−3)=16>0, so there are two distinct real roots. The formula gives x=(2±4)/2, or 3 and −1. §3.5
  2. P(x)=(x−3)(x+1). Substituting x=3 gives 9−6−3=0. §3.5
  3. x=4cos(π/3)=2 and y=4sin(π/3)=2√3, so (x,y)=(2,2√3). §3.6
  4. By the addition theorem, sin(π/4+π/6) = sin(π/4) cos(π/6) + cos(π/4) sin(π/6) = (√2/2)(√3/2) + (√2/2)(1/2), which equals (√6+√2)/4≈0.966. The angle 5π/12=75° is in quadrant I just below π/2, where sine is 1, so a positive value just under 1 fits. §3.5

Slips in the notes

These are source-checked issues. Printed page numbers refer to the lecture notes.

  1. Printed page 27, composition label: the sentence says the composition “f∘g” is defined, but the condition and displayed formula define “g∘f”, with (g∘f)(x)=g(f(x)). The latter is the consistent statement: if f:X→Y, g:D(g)⊆Y→Z and Im(f)⊆D(g), then g∘f:X→Z is defined.
  2. Printed page 28, “no general formulas”: for degree 5 and above, what does not exist is a general formula in radicals (Abel–Ruffini). Roots can still be found numerically, and particular polynomials can still be solved.
  3. Printed page 29, radian arc: the notes say the arc runs “from (0,1)” to P. The angle is measured from the positive x-axis, so the arc starts at (1,0).
  4. Printed page 33, W(e): the range of ex is written W(e), from German Wertebereich. It means the same as Im(f) used elsewhere in the chapter.
