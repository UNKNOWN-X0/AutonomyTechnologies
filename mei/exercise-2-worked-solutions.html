Exercise 2.1: Absolute values and inequalities

Absolute value is distance from zero. Splitting at sign changes turns these expressions into ordinary inequalities on intervals.

Connected topic: Absolute values and inequalities (§2.3) explain the distance interpretation and safe case splitting.

1a(i): Sketch x2 − 2|y| > 1

Try first: isolate |y|, then check where the resulting upper bound is non-negative.

Attempted it? Open the worked steps

1a(i) · Two unbounded curved bands

  1. Move the absolute-value term to the right: 2|y| < x2 − 1. Since the left side is non-negative, solutions require x2 − 1 > 0, so |x| > 1.

  2. For those x, divide by 2 and remove the absolute value as a two-sided bound:

    −(x2 − 1)/2 < y < (x2 − 1)/2,   x < −1 or x > 1

  3. The solution is the interior between the curves y = ±(x2 − 1)/2 on the two outer sides |x| > 1. The curves and the vertical cutoffs x = ±1 are excluded. At |x| = 1 the only possible y would be 0, but the original inequality is strict and fails there.

  4. Check: at x = 2, the condition is |y| < 3/2; at x = 0 it has no solution.

1a(ii): Sketch |x| + |y| = 2

Try first: split the plane into quadrants and find where the boundary meets each axis.

Attempted it? Open the worked steps

1a(ii) · A diamond boundary

  1. On each quadrant, replace absolute values by the corresponding signed coordinates. For example, when x ≥ 0 and y ≥ 0, the equation is x + y = 2.

  2. Setting one coordinate to zero gives the four vertices (2, 0), (0, 2), (−2, 0), and (0, −2). Between consecutive vertices the equation is linear.

  3. Join those points with straight segments and include the whole boundary, because equality is required. The enclosed diamond itself is not the requested set.

  4. Check: (1, 1) lies on it; (0, 0) and (2, 2) do not.

1b(i): Solve |x + 1| − |x − 1| = 1

Try first: split at −1 and 1, where the expressions inside the absolute values change sign.

Attempted it? Open the worked steps

1b(i) · Solve by intervals

  1. If x ≤ −1, both distances simplify to −(x+1) and −(x−1); their difference is −2, so there is no solution there.

  2. If −1 ≤ x ≤ 1, the expression is (x+1) − (1−x) = 2x. Setting 2x = 1 gives x = 1/2, which lies in this interval.

  3. If x ≥ 1, the expression is (x+1) − (x−1) = 2, not 1.

  4. Answer: {1/2}. The interval check is essential: each simplified equation is valid only in its own case.

1b(ii): Solve √x − 12 < x − 2

Try first: write the square-root domain and make sure both sides are non-negative before squaring.

Attempted it? Open the worked steps

1b(ii) · Domain first, then square

  1. The radicand requires x − 12 ≥ 0, so x ≥ 12. On this domain, x − 2 ≥ 10, so both sides are non-negative and squaring preserves the inequality.

  2. Square and simplify:

    x − 12 < (x − 2)2 ⇔ 0 < x2 − 5x + 16

  3. The quadratic is always positive: its discriminant is 25 − 64 = −39 < 0 and its leading coefficient is positive. Thus every x in the domain works.

  4. Answer: [12, ∞). For instance, x = 12 gives 0 < 10, confirming the boundary is included.

Exercise 2.2: Supremum and infimum

A supremum is a least upper bound; it need not be a member of the set. A maximum must belong to the set, and the same distinction applies to infimum and minimum.

Connected topic: Real numbers, completeness, supremum and infimum (§2.2) give the bound definitions and the ε-characterisation used here.

2a(i): Find the bounds and extrema of M1 = (0, 1]

Try first: identify the numbers approached at both ends and check which endpoints the interval includes.

Attempted it? Open the worked steps

2a · The half-open interval

  1. Every member is at most 1, and 1 belongs to M1. Therefore sup M1 = max M1 = 1.

  2. Every member is positive, so 0 is a lower bound. Values can be chosen arbitrarily close to 0 from above, so no larger number is a lower bound. Thus inf M1 = 0.

  3. Because 0 is not in the interval, M1 has no minimum. Summary: sup = max = 1; inf = 0; no minimum.

2a(ii): Find the bounds and extrema of M2 = {1/n : n ∈ ℕ}

Try first: list the first few values and determine their limit as n grows.

Attempted it? Open the worked steps

2a · A decreasing sequence of reciprocals

  1. Here ℕ = {1, 2, …}, as defined in the MEI notes. The first term is 1, and 1/n ≤ 1 for every positive n, so sup M2 = max M2 = 1.

  2. All terms are positive. Given any ε > 0, choose a natural n > 1/ε; then 1/n < ε. Hence no positive number is a lower bound, and inf M2 = 0.

  3. Zero is not one of the terms, so there is no minimum. Summary: sup = max = 1; inf = 0; no minimum.

2a(iii): Find the bounds and extrema of M3 = { (−1)n(1 + 1/n) : n ∈ ℕ }

Try first: separate even n from odd n; their signs differ, so each subsequence controls a different extreme.

Attempted it? Open the worked steps

2a · Separate positive and negative terms

  1. For odd n, the terms are negative: −(1 + 1/n). Their smallest value occurs at the smallest odd n, n = 1, giving −2. All later negative terms are greater than −2.

  2. For even n, terms are positive: 1 + 1/n. Their largest value occurs at the smallest even n, n = 2, giving 3/2. All later positive terms are smaller.

  3. Summary: inf M3 = min M3 = −2; sup M3 = max M3 = 3/2. Both bounds are attained.

2b: Show that M = {x ∈ ℚ : x2 < 2} has infinitely many rational upper bounds but no rational supremum

Try first: show that every rational greater than √2 is an upper bound, then ask whether such a bound can be the least rational one.

Attempted it? Open the worked steps

2b · The least upper bound is irrational

  1. M is non-empty (1 ∈ M), and every x ∈ M satisfies x < √2. Each rational q > √2 is therefore an upper bound. There are infinitely many: for example, choose q = 2 + 1/n for each positive integer n; all exceed √2 and give distinct rationals.

  2. Suppose a rational S were supℚ M. All members of M lie below √2, and rationals in M approach it from below because ℚ is dense in ℝ. Thus √2 is the real least upper bound.

  3. By the given ε-characterisation, a supremum S must be an upper bound, so S ≥ √2. For every ε > 0, there is x ∈ M with x > S − ε, while every x ∈ M is below √2; hence S − ε < √2 for every ε, forcing S ≤ √2. Therefore S = √2. But that is irrational, contradicting S ∈ ℚ.

  4. Conclusion: M has infinitely many upper bounds in ℚ but no supremum in ℚ. In ℝ its supremum is √2.

Exercise 2.3: Sums, products, binomial coefficients

Use index changes to expose patterns, cancellation to simplify sums, and combinations to count pairs or selections.

Connected topic: Sums, products and binomial coefficients (§2.4) define the notation, geometric sums and counting rules used below.

3a: Write the odd square numbers from 121 to 2401 as a sum

Try first: represent the odd bases as a sequence with step 2, starting at 11 and ending at 49.

Attempted it? Open the worked steps

3a · Index the odd bases

  1. The odd integers in the stated range are 11, 13, …, 49. Starting with k = 0, the kth base is 11 + 2k. It reaches 49 when k = 19.

  2. Therefore the requested sum is:

    ∑k=019 (11 + 2k)2

  3. Check: the first term is 11² = 121 and the last is (11 + 38)² = 49² = 2401; there are 20 odd squares.

3b(i): Simplify the difference of two sums

Try first: shift the first index so both sums contain the same powers of x, then compare coefficients.

Attempted it? Open the worked steps

3b(i) · Coefficient cancellation

  1. Re-index the first sum with j = k + 1. The bracket becomes Σj=110 jxj − Σj=010 (j + 1)xj.

  2. The constant term is −1. For each power xj, 1 ≤ j ≤ 10, the coefficient is j − (j + 1) = −1. Thus the bracket is −(1 + x + … + x10).

  3. Multiply by (1 − x) and use the finite geometric-sum identity:

    −(1 − x)(1 + x + … + x10) = −(1 − x11) = x11 − 1

  4. Answer: x11 − 1, valid for every real x, including x = 1 because the polynomial identity has no division by 1 − x.

3b(ii): Compute the nested sum and product

Try first: evaluate the inner product for each m; look for a zero factor before multiplying numbers.

Attempted it? Open the worked steps

3b(ii) · A zero term removes one product

  1. At m = 1, the product includes k = 1, whose factor is 1² − 1 = 0. That whole inner product is 0.

  2. At m = 2, the product has k = 2 and k = 3:

    (22 − 1)(32 − 1) = 3 · 8 = 24

  3. Add the two outer terms: 0 + 24 = 24.

3b(iii): Simplify Σ C(n,k)

Try first: use the binomial theorem with both entries equal to 1.

Attempted it? Open the worked steps

3b(iii) · Count all subsets

  1. Expand (1 + 1)n by the binomial theorem:

    (1 + 1)n = ∑k=0n C(n,k) · 1n−k · 1k

  2. Every power of 1 equals 1, so the requested sum equals 2n. This also counts all subsets of an n-element set.

  3. Answer: 2n.

3c: Find the number of guests from 66 clinks

Try first: one clink corresponds to one unordered pair of distinct guests.

Attempted it? Open the worked steps

3c · Count unordered pairs

  1. With g guests, every pair clinks once, so the number of clinks is C(g,2) = g(g − 1)/2.

  2. Set the count to 66 and solve:

    g(g − 1)/2 = 66 ⇔ g2 − g − 132 = 0 ⇔ (g − 12)(g + 11) = 0

  3. The roots are 12 and −11; only a positive guest count is possible. There are 12 guests.

  4. Check: 12·11/2 = 66 distinct pairs.

3d: Birthday probability for 27 students

Try first: calculate the complement event that every birthday is different, then subtract from 1.

Attempted it? Open the worked steps

3d · Use the complement probability

  1. Assume independent, equally likely birthdays on 365 days, as specified. The first student can have any birthday; for no match, the next has 364 choices, then 363, continuing down to 339 choices for the 27th student.

  2. There are 36527 equally likely birthday assignments overall. Hence:

    P( all birthdays different ) = 365 · 364 · … · 339 / 36527

    P( at least one shared birthday ) = 1 − 365 · 364 · … · 33936527 ≈ 0.6269

  3. Answer: about 62.7%. This is the probability of at least one matching pair, not the expected number of matching pairs.

Exercise 2.4: Order axioms

Each result follows from the field and order axioms, not from assuming familiar arithmetic laws. Use uniqueness of inverses, distributivity, trichotomy, and compatibility of order with addition and positive multiplication.

Connected topic: Real numbers as an ordered field (§2.2) lists the axioms from which each identity and inequality is derived.

4i: Prove a · 0 = 0

Try first: write 0 as 0 + 0 and use distributivity, then cancel a term from both sides.

Attempted it? Open the worked steps

4i · Distributivity and cancellation

  1. Since 0 = 0 + 0, distributivity gives a·0 = a(0 + 0) = a·0 + a·0.

  2. Add the additive inverse of a·0 to both sides. The left becomes 0 and the right becomes a·0, so a·0 = 0.

  3. This argument works for every a and uses only the additive identity, distributivity and additive inverses.

4ii: Prove −a = (−1)·a

Try first: show that (−1)·a added to a equals zero, then use uniqueness of the additive inverse.

Attempted it? Open the worked steps

4ii · Identify the additive inverse

  1. Distributivity gives (−1)·a + a = ((−1) + 1)·a.

  2. (−1) + 1 = 0, and part i) gives 0·a = 0. Therefore (−1)·a + a = 0.

  3. An additive inverse is unique, so (−1)·a = −a.

4iii: Prove (−a)·(−b) = a·b

Try first: replace each negative by multiplication by −1; establish (−1)(−1) = 1 from part ii).

Attempted it? Open the worked steps

4iii · Two negative factors

  1. Part ii) gives −a = (−1)a and −b = (−1)b. Associativity and commutativity of multiplication then give (−a)(−b) = ((−1)(−1))(ab).

  2. Apply part ii) to the element −1: −(−1) = (−1)(−1). The additive inverse of −1 is 1, so this product equals 1.

  3. Thus (−a)(−b) = 1·ab = ab.

4iv: Prove ab = 0 ⇒ a = 0 or b = 0

Try first: assume a ≠ 0 so its multiplicative inverse exists, then multiply the equation by that inverse.

Attempted it? Open the worked steps

4iv · Use the inverse of a non-zero factor

  1. Suppose ab = 0. If a = 0, the conclusion already holds.

  2. Otherwise a ≠ 0, so a−1 exists in the field. Multiply ab = 0 by a−1:

    a−1(ab) = a−1 · 0

  3. Associativity and the zero-product result from i) reduce this to b = 0. In either case, a = 0 or b = 0.

  4. The existence of inverses for non-zero elements is the crucial field property; it need not hold in an arbitrary ring.

4v: Prove 1 > 0

Try first: use trichotomy and rule out 1 = 0 and 1 < 0.

Attempted it? Open the worked steps

4v · Exclude the other order cases

  1. In a field, 1 ≠ 0. Trichotomy therefore leaves either 1 > 0 or 1 < 0.

  2. Assume for contradiction that 1 < 0. Add −1 to both sides: 0 < −1.

  3. The product of two positive elements is positive, so (−1)(−1) > 0. Part iii), or the identity established in its proof, says (−1)(−1) = 1. Thus 1 > 0, contradicting 1 < 0.

  4. The negative case is impossible. Therefore 1 > 0.

4vi: Prove a² > 0 for a ≠ 0

Try first: split into a > 0 and a < 0, and express the second square using −a.

Attempted it? Open the worked steps

4vi · A non-zero square is positive

  1. By trichotomy, a ≠ 0 means either a > 0 or a < 0.

  2. If a > 0, the product of positive elements gives a·a > 0.

  3. If a < 0, then −a > 0. Its square is positive, and part iii) gives (−a)(−a) = a·a.

  4. Both cases establish a² > 0.

4vii: Show a < b and c < 0 imply ac > bc

Try first: translate a < b into a positive difference, and identify the sign of c(b − a).

Attempted it? Open the worked steps

4vii · Multiplication by a negative reverses order

  1. Add −a to the inequality a < b. Compatibility of order with addition gives 0 < b − a.

  2. Because −c > 0 and b − a > 0, the product (−c)(b − a) is positive. The identity (−c)(b − a) = −(c(b − a)) follows from distributivity and additive inverses, so c(b − a) < 0.

  3. Expand: c(b − a) = cb − ca < 0. Add ca to both sides to obtain cb < ca.

  4. Commutativity gives ac > bc. The direction reverses because c is negative.

Self-Study 2.5: Absolute values and inequalities

The first condition describes a diamond in the plane; the one-variable inequalities are handled by splitting intervals and checking domains before squaring.

Connected topic: Absolute values and inequalities (§2.3) connect distance regions with interval solutions.

5a: Sketch |x| + |y − 2| < 5

Try first: interpret each term as a distance from a coordinate, then locate the four axis-parallel intercepts.

Attempted it? Open the worked steps

5a · Interior of a translated diamond

  1. |x| is horizontal distance from x = 0; |y − 2| is vertical distance from y = 2. Their sum is the Manhattan distance from (0, 2).

  2. Set one distance to zero to find the vertices: x = ±5 when y = 2; and y − 2 = ±5 when x = 0, giving y = 7 and y = −3.

  3. The strict inequality keeps the interior of the diamond with vertices (−5,2), (5,2), (0,7), and (0,−3). The boundary is excluded.

5b(i): Solve |x + 3| + |x − 3| > 8

Try first: inside [−3,3] the two distances add to a constant; outside it they grow with |x|.

Attempted it? Open the worked steps

5b(i) · Sum of distances from two points

  1. For −3 ≤ x ≤ 3, |x+3| = x+3 and |x−3| = 3−x. Their sum is 6, which is not greater than 8.

  2. For x > 3, both terms are positive expressions, so the sum is (x+3)+(x−3)=2x. The inequality gives x > 4.

  3. For x < −3, both absolute values reverse sign and the sum is −2x. Then −2x > 8 gives x < −4.

  4. Answer: (−∞, −4) ∪ (4, ∞). The endpoints are excluded because the original inequality is strict.

5b(ii): Solve √(x − 4)(x − 1) ≤ 2 − x

Try first: require a non-negative radicand and a non-negative right side before squaring.

Attempted it? Open the worked steps

5b(ii) · Combine domain restrictions, then square

  1. The radicand is non-negative when x ≤ 1 or x ≥ 4. Since a square root is non-negative, the right side 2 − x must also be non-negative, so x ≤ 2. Together these restrictions reduce the domain to x ≤ 1.

  2. On this domain both sides are non-negative, so squaring is equivalent:

    (x − 4)(x − 1) ≤ (2 − x)2 ⇔ x2 − 5x + 4 ≤ x2 − 4x + 4 ⇔ x ≥ 0

  3. Intersect with x ≤ 1 to obtain [0,1].

  4. Check: at 0, √4 = 2, equality holds; at 1, 0 ≤ 1. Values below 0 fail the squared inequality.

Self-Study 2.6: Sets, products and complements

Use ordered-pair membership for products and remember that every complement depends on its declared universe.

Connected topic: Set inclusion, Cartesian products and complements (§1.2) define the membership tests used below.

6a: Prove A × B ⊂ C × D when A ⊂ C and B ⊂ D

Try first: take an arbitrary ordered pair from A × B and track each coordinate separately.

Attempted it? Open the worked steps

6a · Element-chasing proof

  1. Let (a,b) ∈ A × B. By definition, a ∈ A and b ∈ B.

  2. A ⊂ C gives a ∈ C, and B ⊂ D gives b ∈ D.

  3. Therefore (a,b) ∈ C × D. Since the chosen pair was arbitrary, A × B ⊂ C × D.

6b: Is the converse true?

Try first: ask what happens when one Cartesian-product factor is empty, so the product contains no pairs.

Attempted it? Open the worked steps

6b · Empty products hide factor membership

  1. The converse would claim A × B ⊂ C × D implies both A ⊂ C and B ⊂ D. This is false when a factor is empty.

  2. For example, let A = {1}, B = ∅, C = ∅, and D = {2}. Then A × B = ∅ and C × D = ∅, so A × B ⊂ C × D, but A is not a subset of C.

  3. If A and B are both non-empty, choose b ∈ B to test any a ∈ A, and choose a ∈ A to test any b ∈ B. The product inclusion then does force A ⊂ C and B ⊂ D.

  4. Conclusion: not in general; it becomes true if both factors A and B are non-empty.

6c: Compute the complements and difference for A = [1,3), B = (2,5] in X = ℝ

Try first: mark each endpoint, then form the union and intersection before taking their complements relative to ℝ.

Attempted it? Open the worked steps

6c · Track open and closed endpoints

  1. A contains 1 but not 3, so its complement contains values below 1 and values at least 3:

    Ac = (−∞,1) ∪ [3,∞)

  2. B excludes 2 and includes 5:

    Bc = (−∞,2] ∪ (5,∞)

  3. The overlap intervals join into A ∪ B = [1,5]. Therefore (A ∪ B)c = (−∞,1) ∪ (5,∞).

  4. The intersection is (2,3), because both endpoints are excluded by at least one interval. Thus (A ∩ B)c = (−∞,2] ∪ [3,∞).

  5. A \ B contains the part of A not in B: [1,2]. The point 2 remains because B is open there; every point just above 2 is removed.

  6. Check: 1 and 2 belong to A \ B; 3 does not belong to A at all.

6d: Find the complement of [1,3] × [1,2] in ℝ²

Try first: a point is outside the rectangle if at least one coordinate lies outside its own closed interval.

Attempted it? Open the worked steps

6d · Outside in either coordinate

  1. A point (x,y) is in the rectangle exactly when 1 ≤ x ≤ 3 and 1 ≤ y ≤ 2.

  2. Negate this conjunction: x < 1 or x > 3 or y < 1 or y > 2.

  3. Thus the complement is:

    ((−∞,1) ∪ (3,∞)) × ℝ   ∪   ℝ × ((−∞,1) ∪ (2,∞))

  4. The rectangle edges are not in the complement because the original intervals are closed.

Self-Study 2.7: Sums, products, binomial coefficients

Match each term to an index, telescope products before expanding them, and use combinations when order does not matter.

Connected topic: Sums, products and binomial coefficients (§2.4) supply the geometric, telescoping and counting identities.

7a: Write 10² − 1/9² + 8² − 1/7² + … + 2² − 1/1² as a sum

Try first: choose an index that makes the positive bases descend by 2 from 10 and the denominators descend from 9.

Attempted it? Open the worked steps

7a · Encode both sequences with one index

  1. For k = 0,1,2,3,4, the positive base 10 − 2k runs 10,8,6,4,2; the denominator 9 − 2k runs 9,7,5,3,1.

  2. Therefore the sum is:

    ∑k=04 ((10 − 2k)2 − 1/(9 − 2k)2)

  3. Check: the final term is 2² − 1/1², as required.

7b(i): Simplify the difference of geometric sums

Try first: write out the powers in both sums and look for the unmatched term.

Attempted it? Open the worked steps

7b(i) · Shifted finite sums

  1. The first sum is 1 + q + … + qn. The second is q−1 + 1 + q + … + qn.

  2. Every term cancels except the initial q−1 in the second sum, which is subtracted:

    Σk=0nqk − Σk=0n+1qk−1 = −q−1 = −1/q

  3. This holds for every q ≠ 0, including q = 1; no geometric-series division by q − 1 is needed.

7b(ii): Simplify the product

Try first: factor the numerator j(j+1) − 2 and separate the product into two telescoping ratios.

Attempted it? Open the worked steps

7b(ii) · Two telescoping products

  1. Factor each term:

    1 − 2/(j(j+1)) = (j2 + j − 2)/(j(j+1)) = ((j−1)(j+2))/(j(j+1))

  2. Split the product into ∏j=2n(j−1)/j and ∏j=2n(j+2)/(j+1). The first collapses to 1/n; the second to (n+2)/3.

  3. Multiply:

    ∏j=2n(1 − 2/(j(j+1))) = (n+2)/(3n)

  4. The formula also gives 1 at n = 1, agreeing with the empty-product convention.

7b(iii): Simplify the alternating binomial sum

Try first: expand (1 + x)n and substitute x = −1.

Attempted it? Open the worked steps

7b(iii) · Binomial theorem at x = −1

  1. The binomial theorem says (1 + x)n = Σk=0nC(n,k)xk.

  2. Set x = −1. For n ≥ 1, the left side is 0, so:

    Σk=0n(−1)kC(n,k) = (1 − 1)n = 0

  3. Answer: 0.

7c: Pick six marbles with at most two striped marbles

Try first: remember there are only four white marbles, so any six-marble selection must include at least two striped ones.

Attempted it? Open the worked steps

7c · Count the allowed composition

  1. At most two striped means 0, 1, or 2 striped marbles. But six marbles cannot be chosen with fewer than two striped because the box has only four white marbles.

  2. Therefore exactly two striped and all four white must be selected. Choose 2 of the 12 striped marbles and 4 of the 4 white ones:

    C(12,2) · C(4,4) = 66 · 1 = 66

  3. Answer: 66 ways.

7d: Find the members from 272 spoken riddles

Try first: distinguish a greeting spoken from one unordered pair. Each member speaks once to each of the other members.

Attempted it? Open the worked steps

7d · Count ordered speaker-listener pairs

  1. Choose the speaker in m ways. That member then greets each of the other m − 1 members once, so the total number of spoken riddles is m(m − 1), not C(m,2). Speaking and listening are different roles, so the two directions between a pair count separately.

  2. Set the ordered-pair count to 272 and solve:

    m(m − 1) = 272 ⇔ m2 − m − 272 = 0 ⇔ (m − 17)(m + 16) = 0

  3. The roots are 17 and −16; only a positive group size is possible. There are 17 members.

  4. Check: each of 17 members speaks to 16 others, giving 17·16 = 272 spoken riddles. If the greetings were mutual and each pair spoke only once, the count would instead be C(m,2), as in Exercise 2.3c.
