Exercise 1.1: Statements

A logical statement is a sentence with one definite truth value. A sentence can be a statement even when we do not know whether it is true; an unassigned variable or an undefined judgement can prevent a definite truth value.

Connected topic: Propositional logic, predicates and quantifiers (§1.1) define statements, open forms and truth values.

1a: Classify the four expressions

Try first: for each sentence, ask whether its variables and context are fixed well enough that it must be true or false.

Attempted it? Open the worked steps

1a · A definite truth value

  1. i. “z is prime.” The value of z has not been given or quantified. This is an open form: it becomes a statement only after a value is assigned to z (or a quantifier is added). As written, it is not a statement.

  2. ii. The claim about Lothar Matthäus and the 2011 Tour de France. It names a particular person and event, with no free variable. It is a factual declarative sentence, so it has a definite truth value whether or not the reader knows it. It is a statement.

  3. iii. “This statement is false.” If it were true, what it says would make it false; if it were false, then what it says would be true. It cannot be assigned a consistent true-or-false value in ordinary two-valued logic. It is not a logical statement.

  4. iv. The conditional involving n and the oak trees. The variable n is free, so different values of n can change the antecedent. The sentence would need a specified n, or a quantifier such as “for every n”. As written, it is not a statement.

1c: Find the guilty suspect

Try first: write each clue as an implication, then test whether Christoph can be guilty.

Attempted it? Open the worked steps

1c · Translate the clues and eliminate cases

  1. Let A, B and C mean that Anton, Bert and Christoph, respectively, are guilty. The three clues become:

    C ⇒ A

    (B ∨ C) ⇒ ¬A

    (¬A ∨ ¬C) ⇒ B

  2. Suppose C were true. The first clue would make A true. Then B ∨ C is true, so the second clue makes ¬A true. That contradicts A; hence C is false.

  3. Because ¬C is true, the antecedent A ∨ ¬C in the third clue is true. Therefore B is true: Bert is guilty.

  4. Now B ∨ C is true, so the second clue gives ¬A. Anton is innocent, and we already found Christoph innocent.

  5. Conclusion: B is true while A and C are false. Bert committed the crime. Substitution checks all three clues: true, true, and true.

Exercise 1.2: Sets

Translate set operations into membership conditions. This keeps the meaning precise even when the sets overlap in a complicated way.

Connected topic: Set operations, Cartesian products and power sets (§1.2) express union, intersection and difference through membership.

2a: Read four regions in the diagram

Try first: translate each expression using “x is in …” before describing the region in words.

Attempted it? Open the worked steps

2a · Convert each expression to a membership test

  1. For i), membership in A \ B means “in A and not in B”. Intersecting with C adds one more “and”:

    x ∈ (A \ B) ∩ C ⇔ (x ∈ A) ∧ (x ∉ B) ∧ (x ∈ C)

    Keep the part shared by A and C that lies outside B.

  2. For ii), union means “or”. Keep every point in C, together with any point that is in A but outside B:

    x ∈ (A \ B) ∪ C ⇔ ((x ∈ A) ∧ (x ∉ B)) ∨ (x ∈ C)

  3. For iii), a complement keeps the points in X that fail membership in the whole union. De Morgan’s law changes “not (P or Q)” to “not P and not Q”:

    ((A \ B) ∪ C)c = ((A \ B)c) ∩ Cc = (Ac ∪ B) ∩ Cc

    So keep points outside C and either outside A or inside B.

  4. For iv), first combine the two differences: A \ C and B \ C together are all of A ∪ B with C removed. Complementing adds C back and keeps the points outside both A and B:

    ((A \ C) ∪ (B \ C))c = ((A ∪ B) \ C)c = (A ∪ B)c ∪ C

  5. Check: in iii) any point inside C is excluded; in iv) every point inside C is included. That opposite treatment is a quick way to catch a misplaced complement.

2b · Operations, products and power sets

  1. A contains the positive even natural numbers; B contains the positive odd natural numbers. Every positive natural number is exactly one of these, so:

    A ∪ B = ℕ

    A ∩ B = ∅

    A \ B = A

    B \ A = B

  2. The Cartesian product asks for ordered pairs whose first entry is in the first factor and second entry is in the second:

    A × B = {(a, b) : a ∈ A, b ∈ B}

  3. Test the two elements of C separately. (2, 3) passes: 2 is even and 3 is odd. (3, 4) fails: 3 is not even and 4 is not odd. Since one element fails, C is not a subset of A × B.

  4. The power set contains every subset of C: the empty set, each one-element subset, and C itself.

    𝒫(C) = {∅, {(2, 3)}, {(3, 4)}, {(2, 3), (3, 4)}}

    There are 2² = 4 subsets, matching the two elements of C.

2c: Prove a set identity by membership

Try first: take an arbitrary x and translate both “set difference” steps into and/not conditions.

Attempted it? Open the worked steps

2c · Element-by-element proof

  1. Take any x. It belongs to the left-hand side exactly when it is in A but not in A \ B:

    x ∈ A \ (A \ B) ⇔ (x ∈ A) ∧ ¬(x ∈ A \ B)

  2. Expand the inner difference: x ∈ A \ B means x ∈ A and x ∉ B. Therefore:

    (x ∈ A) ∧ ¬((x ∈ A) ∧ (x ∉ B))

  3. Because we already know x ∈ A, the negated inner condition reduces to x ∈ B. Thus membership is equivalent to x ∈ A and x ∈ B:

    x ∈ A \ (A \ B) ⇔ x ∈ A ∩ B

  4. This is true for every x, so both sets contain exactly the same elements. Hence A \ (A \ B) = A ∩ B.

Exercise 1.3: Quantifiers — students and courses

Let S be the student set, C the course set, and B(s, c) mean that student s passed course c. The order of “for all” and “there exists” determines who may vary.

Connected topic: Predicates, quantifier order and negation (§1.1) define the domain and the order in which choices are made.

3a: Translate “a bright spark passes everything”

Try first: decide whether the student is chosen before or after the course, and whether one student must pass every course.

Attempted it? Open the worked steps

3a · One student, all courses

  1. “There is a student” gives ∃s. “Passes everything” says that same student passes every course, giving ∀c. The correct choice is b) ∃s ∈ S ∀c ∈ C: B(s, c).

  2. Translate the other choices to see the difference:

    ChoiceMeaning
    a) ∀s ∃c B(s,c)Every student has passed at least one course; it may be a different course for each student.
    c) ∃s ∃c B(s,c)At least one student has passed at least one course.
    d) ∀c ∃s B(s,c)Every course has at least one student who passed it; the student may vary by course.

  3. Check: ∃s∀c is stronger than ∀s∃c. The former fixes one student and then asks about every course.

3b: Translate “nobody passed the whole programme”

Try first: negate “there is a student who passed every course”, then swap the quantifiers as you push the negation inward.

Attempted it? Open the worked steps

3b · Each student missed a course

  1. “Nobody has made it through” means there is no student who passed all courses:

    ¬(∃s ∈ S ∀c ∈ C: B(s, c))

  2. Negating ∃ changes it to ∀; negating ∀ changes it to ∃; the predicate is negated too:

    ∀s ∈ S ∃c ∈ C: ¬B(s, c)

    So the answer is d): every student has at least one course they have not passed.

  3. The other options say:

    ChoiceMeaning
    a) ∃s ∀c ¬B(s,c)At least one student has passed no courses.
    b) ∀c ∃s ¬B(s,c)Every course has at least one student who has not passed it.
    c) ∀s ∀c ¬B(s,c)No student has passed any course.

  4. Check: the correct statement allows a student to have passed most courses; it only requires one unpassed course for each student.

3c: Translate “a course everyone passes”

Try first: identify the one course that must work for every student, then contrast it with “each student has some course”.

Attempted it? Open the worked steps

3c · One course, all students

  1. “There is a course” gives ∃c; “every student passes it” gives ∀s. The correct choice is a) ∃c ∈ C ∀s ∈ S: B(s, c).

  2. The other formulas mean:

    ChoiceMeaning
    b) ∀c ∃s B(s,c)Every course has some student who passed it.
    c) ∀s ∃c B(s,c)Every student has passed at least one course.
    d) ∃s ∀c B(s,c)Some student has passed every course.

  3. Check: in a), one course is chosen first and then tested for every student. In d), it is one student tested against every course.

Self-Study 1.4: Statements

This review combines statement classification, truth tables, implication language and translating ordinary “unless” sentences.

Connected topic: Statements, truth tables and logical equivalence (§1.1) define the tests used below.

4a: Decide whether each sentence is a statement

Try first: check whether the sentence asserts something with a definite truth value, not whether you personally know the value.

4a · Assertion or open judgement?

  1. i. The conditional about a father having a sibling. It is a complete declarative sentence with a fixed family relation as its subject. It can be true or false, even if the family facts are unknown. It is a statement.

  2. ii. “The formula is beautiful.” No formula or precise criterion for “beautiful” is specified. Under the guide’s logical definition, the sentence has no definite truth value. As written, it is not a logical statement.

4c · Conditional direction and truth value

  1. Use C = cats have wings, D = dogs have wings, P = parrots have wings. The given assignment makes all three false.

  2. i. Cats have wings only if dogs have wings. “Only if” puts the necessary condition second: C ⇒ D, read “If cats have wings, then dogs have wings.” It is true because the antecedent C is false.

  3. ii. Parrots have wings only if dogs have wings. Formula P ⇒ D, read “If parrots have wings, then dogs have wings.” It is true because P is false.

  4. iii. Parrots have wings if dogs have wings. The condition after “if” is the antecedent: D ⇒ P, read “If dogs have wings, then parrots have wings.” It is true because D is false.

  5. iv. If cats or dogs have wings, then both cats and dogs have wings. Formula (C ∨ D) ⇒ (C ∧ D). It is true because its antecedent is false. All four sentences are true for the supplied assignment; a conditional with a false antecedent is true in the truth-table definition.

4d: Show that a conditional is not a tautology

Try first: to make an implication false, make its antecedent true and its consequent false.

Attempted it? Open the worked steps

4d · One counterexample is enough

  1. Choose A = false and B = true. Then A ⇒ B is true (false antecedent), while B ⇒ A is false (true antecedent and false consequent).

  2. The outer implication is therefore true ⇒ false, which is false:

    (A ⇒ B) ⇒ (B ⇒ A) = T ⇒ F = F

  3. A tautology must be true for every assignment. This single false row proves the formula is not a tautology.

4e: Translate “if”, “only if” and “unless”

Try first: “B unless G” means that if G is absent, B does not happen. Compare the directions after translating.

Attempted it? Open the worked steps

4e · Mirror conditions

  1. Let B mean the mirror breaks, G mean it is made of glass, and W mean it is high on the wall.

  2. i. Breaks if it is made of glass: glass is sufficient for breaking, so G ⇒ B.

  3. ii. Breaks only if it is made of glass: glass is necessary for breaking, so B ⇒ G.

  4. iii. Unless it is made of glass, it will not break: if it is not glass, it does not break: ¬G ⇒ ¬B. By contraposition, this is equivalent to B ⇒ G.

  5. iv. It is high on the wall, but will not break unless it is glass: “but” is conjunction, so the full formula is W ∧ (¬G ⇒ ¬B), equivalently W ∧ (B ⇒ G).

  6. Equivalent pair: ii) and iii) express the same conditional. In iv), that conditional is joined to the extra requirement W, so iv) is not generally equivalent to ii).

5c: Prove a difference identity

Try first: expand “not in B \ C” and distribute “and” over “or”.

5c · Use membership and distributivity

  1. Take arbitrary x ∈ X. It belongs to the left side when x ∈ A and it is not true that x is in B but outside C:

    x ∈ A \ (B \ C) ⇔ (x ∈ A) ∧ ¬((x ∈ B) ∧ (x ∉ C))

  2. By De Morgan’s law, the negated bracket says x ∉ B or x ∈ C. Distribute the outer “and”:

    (x ∈ A) ∧ ((x ∉ B) ∨ (x ∈ C))

    ⇔ ((x ∈ A) ∧ (x ∉ B)) ∨ ((x ∈ A) ∧ (x ∈ C))

  3. Translate the two terms back into sets: the first is A \ B; the second is A ∩ C. Therefore both sides have exactly the same members:

    A \ (B \ C) = (A \ B) ∪ (A ∩ C)

6a · Truth values in ℕ, ℤ and ℝ+

  1. First negate each statement by swapping ∀ and ∃ and negating the relation:

    StatementNegation
    i) ∃x ∈ M ∀y ∈ M: x < y∀x ∈ M ∃y ∈ M: x ≥ y
    ii) ∀y ∈ M ∃x ∈ M: x < y∃y ∈ M ∀x ∈ M: x ≥ y
    iii) ∃x ∈ M ∀y ∈ M: x + y = 1∀x ∈ M ∃y ∈ M: x + y ≠ 1
    iv) ∀y ∈ M ∃x ∈ M: x + y = 1∃y ∈ M ∀x ∈ M: x + y ≠ 1

  2. i) False in all three domains. If x is in M, the universal condition must also hold at y = x, which would require x < x. That is false for every number.

  3. ii) For ℕ, take y = 1; there is no smaller natural number in this course’s convention, so the claim is false. For ℤ, choose x = y − 1 for any integer y; this is always an integer smaller than y, so the claim is true. For ℝ+, choose x = y/2 for each y; it is still positive and is smaller than y. Thus the values are F, T, T.

  5. iv) For ℕ, choose y = 2: the only possible x is −1, which is not natural, so false. In ℤ, for every y choose x = 1 − y, which is an integer, so true. In ℝ+, again y = 2 would require x = −1, not positive, so false. The values are F, T, F.
