2.1 Number Systems

The sets grow by solving equations that smaller number systems cannot always solve. Knowing which set contains a number determines which tools are valid.

Number-system inclusionℕ ⊊ ℤ ⊊ ℚ ⊊ ℝ; irrational numbers = ℝ\ℚHere ℕ={1,2,…}; ℕ0=ℕ∪{0}. A rational is p/q with p∈ℤ, q∈ℕ and p,q coprime.

Integers add negatives to ℕ. Rationals add quotients with non-zero integer denominator. The real numbers add limits such as √2 that cannot be expressed as a rational quotient. For example, √2 is irrational: if √2=p/q in lowest terms, then p2=2q2 makes p even; substituting p=2m makes q even too, contradicting lowest terms.

Binary uses place values that are powers of two. A bit string [am…a0]2 represents Σk=0mak2k, where each ak is 0 or 1. For a fixed-point example, [10.11]2=2+1/2+1/4=2.75. The field ℤ2 uses arithmetic modulo 2; ordinary binary integer addition and multiplication instead represent integer arithmetic and do not make the set of finite bit strings a field.

Worked example · classify and convert

  1. √49=7, so it is natural, integer, rational and real.
  2. −7/3 is rational and real, but not an integer.
  3. √2 is real and irrational, so it is not rational.
  4. [11010]2=1·24+1·23+0·22+1·2+0=26. Check: 16+8+2=26.

Trap: zero is not in ℕ under these notes’ convention. Write ℕ0 when zero is included. Also, an integer written as a decimal or fraction can still belong to a smaller set, such as 6/3=2∈ℤ.

2.2 Real Numbers

The real-number rules explain why algebraic transformations are legitimate and why limits do not leave gaps in the number line.

Field and orderℝ is a complete ordered fieldThe notes list 9 field axioms, 4 order axioms and 1 completeness axiom. A field has 0, 1, additive inverses and multiplicative inverses for non-zero elements.

The field axioms encode commutativity, associativity, neutral elements, inverses and distributivity. The order axioms make < a total, transitive order compatible with addition and multiplication by positive numbers. Together these support the familiar algebra of inequalities. ℤ is not a field because, for example, 1/3 is not an integer. ℚ is an ordered field, but it is not complete.

Upper bound and supremumS = sup(M) iff (i) x≤S for every x∈M and (ii) S≤T for every upper bound T of MThe supremum is the least upper bound. It need not belong to M. An infimum is the greatest lower bound.

For M={1, 1/2, 1/3,…}, sup(M)=1 and inf(M)=0. The maximum is 1 because 1∈M; there is no minimum because 0∉M. The completeness axiom says every non-empty real subset bounded above has a supremum in ℝ. It is the property that fills the “gaps” missing in ℚ.

n-th root from completenessrootn(x) = sup{r∈ℚ : r≥0 and rn≤x}, for x≥0rootn(x) is the unique non-negative real number whose n-th power is x.

Worked example · identify bounds and extrema

Let M={1−1/n : n∈ℕ}. Its first values are 0, 1/2, 2/3, 3/4, … . Every value is below 1, so 1 is an upper bound. Values approach 1, so no smaller number is an upper bound: sup(M)=1. But 1∉M, so M has no maximum. The smallest member is 0, hence inf(M)=min(M)=0.

Trap: a supremum is not automatically a maximum. First establish the least or greatest bound, then check whether it belongs to the set.

2.3 Absolute Values and Inequalities

Absolute value turns signs into distance, while the order axioms let you solve distance constraints as intervals.

Absolute value|x| = x if x≥0; |x| = −x if x<0|x| is distance from x to 0; |x−a| is distance from x to a. In particular, √(x2)=|x|.
Absolute-value laws|xy|=|x||y|; ||x|−|y|| ≤ |x+y| ≤ |x|+|y|The right-hand inequality is the triangle inequality. Equality is possible.

For c≥0, |x−a|≤c is equivalent to a−c≤x≤a+c. It describes the closed interval of points no more than c from a. For c>0, |x−a|<c gives an open interval. An inequality with a “greater than” sign usually describes the outside of an interval. Splitting at the point where the expression changes sign is a reliable general method.

Worked example · solve a distance inequality

Solve |2x−1|≤5. By the two-sided form, −5≤2x−1≤5. Add 1: −4≤2x≤6. Divide by 2: −2≤x≤3. The centre is 1/2 and the radius is 5/2, consistent with the interval endpoints.

Sign check: squaring both sides can introduce solutions unless both sides are known to be non-negative. Also, √(x2) is |x|, not always x.

  1. x lies within distance c of a; for c≥0, a−c≤x≤a+c. §2.3

2.4 Sums, Products, Binomial Coefficient

Summation and product notation compress repeated operations. Factorials count arrangements; binomial coefficients count selections and become the weights in expansions.

Summation and productΣk=mnak = am+…+an; Πk=mnak = am·…·anRead the index bounds inclusively. A constant factor c can be taken outside a sum; for a product it becomes c raised to the number of factors.
Factorial and binomial coefficientn! = Πk=1nk, 0! = 1; C(n,k) = n!/[k!(n−k)!]For 0≤k≤n. C(n,k) counts k-element subsets chosen from n distinct elements, with order ignored.
Pascal identity and binomial theoremC(n,k)+C(n,k+1)=C(n+1,k+1); (a+b)n=Σk=0nC(n,k)an−kbkThe Pascal identity is valid for 0≤k≤n−1. The notes state a,b≠0; the polynomial identity also holds when either is zero. The theorem gives n+1 terms; powers of a descend while powers of b rise.

Useful coefficient properties are C(n,0)=C(n,n)=1 and C(n,k)=C(n,n−k). Pascal’s identity says adjacent entries combine to form the next row. The binomial theorem generalises the familiar square and cube patterns.

Worked example · expand and count

Expand (x+2)4. The row of coefficients is 1, 4, 6, 4, 1, so the terms are x4, 4x3·2, 6x2·22, 4x·23, and 24. Thus (x+2)4=x4+8x3+24x2+32x+16. Check the endpoints: the leading term is x4, and the constant is 16.

Separately, the number of 3-person groups from 8 people is C(8,3)=8·7·6/(3·2·1)=56; ordering the group members would overcount each group 3! times.

Memory hook: in the term indexed by k, the exponent on a is n−k and the exponent on b is k. Check that each term’s exponents add to n.

  1. It counts selections where order does not matter; permutations count orderings. §2.4
  2. 1, 4, 6, 4, 1. §2.4

2.5 Mathematical Induction

Induction proves infinitely many linked claims using a finite argument: establish a starting case, then show each true case passes the claim to the next one.

Induction principleProve A(n0), and prove A(n)⇒A(n+1) for arbitrary n≥n0Then A(n) holds for every integer n≥n0. State the starting index and keep the induction hypothesis available in the step.

Write the induction step as a conditional: assume A(n) for an arbitrary allowed n, and use it to prove A(n+1). Do not assume the result you are trying to prove. The base case starts the chain; the implication advances it. For two-step induction, verify two consecutive base cases and advance from n to n+2, which covers both parities.

Bernoulli’s inequality(1+x)n ≥ 1+nx, for n∈ℕ and x≥−1In the notes’ first proof, x is restricted to x≥−1; this makes 1+x non-negative so multiplying preserves the inequality.
Extended Bernoulli inequality(1+x)n ≥ 1+nx, for n∈ℕ and x≥−2Use two-step induction: prove n=1 and n=2, then advance from n to n+2.

In the extended step, (1+x)n+2=(1+x)2(1+x)n. The square factor is non-negative. Applying the hypothesis and expanding leaves the extra term x2(2n+1+nx), which is non-negative for x≥−2 and n≥1.

Worked example · sum the first n integers

Claim: 1+2+…+n=n(n+1)/2 for n∈ℕ.

  1. Base: n=1 gives 1=1·2/2.
  2. Hypothesis: assume 1+…+n=n(n+1)/2.
  3. Step: 1+…+n+(n+1)=n(n+1)/2+(n+1)=(n+1)(n+2)/2.
  4. This is the claimed formula with n replaced by n+1, so it holds for all n∈ℕ.

Trap: checking several values is not an induction proof. In the step, n is arbitrary—not one particular example—and the induction hypothesis must be stated before it is used.

Explain it

Answer aloud in complete sentences. Then compare with the model answer. (Retrieval and explanatory questioning [MIS, AMN, NEW].)

  1. Why does being expressible as p/q not guarantee a unique written fraction?
  2. Why are field and order axioms not enough to define ℝ?
  3. When is a supremum a maximum?
  4. Why is √(x2) not always x?
  5. When should you use a binomial coefficient instead of a permutation count?
  6. Why does induction need both a base case and a step?
Show model answers
  1. Many numerator-denominator pairs represent the same quotient, such as 2/3 and 4/6. Requiring coprime numerator and denominator gives the reduced representation used in the notes.
  2. ℚ satisfies the field and order rules too, but it has gaps. Completeness distinguishes ℝ by guaranteeing least upper bounds for non-empty bounded-above subsets.
  3. When the supremum belongs to the set. A supremum can bound a set without being one of its elements, as with {1−1/n}.
  4. The square root is non-negative. If x is negative, the non-negative number whose square is x2 is −x, so the result is |x|.
  5. Use C(n,k) when selecting k distinct objects from n and order does not matter. If different orders count as different outcomes, use a permutation count.
  6. The base case starts the chain. The step says every true case passes truth to the next one; together they cover every index from the starting point onward.

Exam-style problems

Allow about 20 minutes for each. Work every part before checking the answer. Afterward, note where you lost a step and revisit the cited sections.

1 · Bounds, distance and counting

Let M={x∈ℝ: |x−2|≤3} and let S be the set of 2-element subsets of {1,2,3,4,5}.

  1. Write M as an interval and give its minimum, maximum, infimum and supremum.
  2. Find all x∈M for which |x|>2.
  3. How many members does S have? Explain why order does not matter.
  4. Find the coefficient of x3y2 in (x+y)5.
Show the worked answer
  1. |x−2|≤3 means −3≤x−2≤3, hence −1≤x≤5. Thus M=[−1,5], and min=inf=−1, max=sup=5. §2.2 §2.3
  2. Within [−1,5], the condition |x|>2 leaves x>2, so (2,5]. §2.3
  3. |S|=C(5,2)=5·4/(2·1)=10. Each pair of distinct elements describes one subset regardless of order. §2.4
  4. The k=2 term is C(5,2)x3y2, so the coefficient is 10. §2.4

2 · Prove the binomial theorem

Let P(n) be the claim (a+b)n=Σk=0nC(n,k)an−kbk, for non-zero real a,b and n∈ℕ.

  1. Verify P(1).
  2. Assume P(n). Multiply its right-hand side by (a+b) to obtain the expression for (a+b)n+1.
  3. Group adjacent terms and use Pascal’s identity to prove P(n+1).
  4. Use the theorem to expand (x+2)4.
Show the worked answer
  1. For n=1, C(1,0)a+C(1,1)b=a+b=(a+b)1. §2.4 §2.5
  2. By P(n), (a+b)n+1=Σ C(n,k)an−kbk(a+b). Distributing gives terms with one extra a and terms with one extra b. §2.4 §2.5
  3. For each interior power, the coefficient is C(n,k)+C(n,k−1)=C(n+1,k), by Pascal’s identity with the index shifted. The endpoint coefficients are 1. Thus the sum is Σk=0n+1C(n+1,k)an+1−kbk; P(n+1) follows. The base and implication prove the theorem for all n∈ℕ. §2.4 §2.5
  4. The coefficients 1,4,6,4,1 give x4+8x3+24x2+32x+16. §2.4
