Exercise 4.1: Mathematical induction

Induction starts from the first valid index and shows that each true case forces the next.

Connected topic: Induction (§2.5).

1a: Prove the finite geometric sum

Try first: check the smallest case n = 1, then add the next term xn + 1 to the formula for n and put everything over 1 − x.

Attempted it? Open the worked steps

1a · Prove the finite geometric sum

  1. Fix a real x ≠ 1 and write Sn for the sum. The claim, for every n ∈ ℕ = {1, 2, 3, …}, is

    Sn = ∑k=0n xk = 1 − xn + 11 − x

  2. Base case n = 1, the smallest natural number in this course. The sum has the two terms 1 + x, and the right side factorises:

    1 − x21 − x = (1 − x)(1 + x)1 − x = 1 + x = S1

  3. Induction hypothesis: the formula holds for some n ∈ ℕ. The next sum adds one term, xn + 1:

    Sn + 1 = Sn + xn + 1 = 1 − xn + 11 − x + xn + 1

  4. Put both terms over the denominator 1 − x, which is not zero because x ≠ 1:

    = 1 − xn + 1 + xn + 1 − xn + 21 − x = 1 − xn + 21 − x

    This is the formula with n + 1 in place of n, so with the base case it holds for every n ∈ ℕ.

  5. Note: the formula is also true at n = 0 (both sides equal 1), so starting there would prove a little more. The sheet asks for n ∈ ℕ, and this course's ℕ starts at 1, so the base case is n = 1, as in Exercise 3.5.

1b: Prove the reciprocal-square-root bound

Try first: start the induction at n = 2, then show that the new term 1/√n + 1 is at least the step from √n to √n + 1.

Attempted it? Open the worked steps

1b · Prove the reciprocal-square-root bound

  1. Write Sn for the sum. The claim starts at n = 2, so that is the base case: S2 = 1 + 1/√2 ≈ 1.707, while √2 ≈ 1.414. The claim holds at n = 2.

    Sn = ∑k=1n 1√k

  2. Induction hypothesis: assume Sn > √n for some n ≥ 2. Adding the next term gives

    Sn + 1 = Sn + 1√n + 1 > √n + 1√n + 1

  3. It is enough to show that the right-hand side is at least √n + 1. Multiply by the positive number √n + 1:

    √n(n + 1) + 1 ≥ n + 1 ⇔ √n(n + 1) ≥ n

    This holds because n(n + 1) > n2.

  4. So Sn + 1 > √n + 1: the claim at n passes to n + 1, and with the base case it holds for every n ≥ 2.

  5. Check: at n = 3 the sum is 1 + 0.707 + 0.577 ≈ 2.28, above √3 ≈ 1.73. At n = 1 both sides equal 1, which is why the strict inequality starts at 2.

Exercise 4.2: Maps

Composition applies f first and g second. For finite-set counts, choose an image for each input while respecting the required property.

Connected topic: Map types and injectivity (§3.2) and counting and binomial coefficients (§2.4).

2a: Is a composition of injections injective?

Try first: assume two composite outputs are equal and unwind the definition of injectivity in reverse order.

Attempted it? Open the worked steps

2a · Is a composition of injections injective?

  1. Suppose (g∘f)(x1)=(g∘f)(x2). This says g(f(x1))=g(f(x2)).

  2. Since g is injective, f(x1)=f(x2). Since f is injective, x1=x2.

  3. Thus g∘f is injective. The codomains need not be equal: the key is that each map is injective on the outputs that occur.

    (g∘f)(x1) = (g∘f)(x2) ⇒ x1 = x2

2b(i): Count all maps M→N

Try first: each of the m elements of M independently chooses one of n target elements.

Attempted it? Open the worked steps

2b(i) · Count all maps M→N

  1. For each input x∈M, a map may assign any of the n elements of N.

  2. There are n choices for each of m independent inputs, so the product rule gives n·n···n=nm maps.

  3. If n=0 and m>0, this gives 0 maps, as expected; for m=0 the unique empty map is counted by 00=1 under the combinatorial convention.

    #(M→N) = nm

2b(ii): Count bijections M→N

Try first: A bijection requires equal cardinalities; when they match, count the possible orderings.

Attempted it? Open the worked steps

2b(ii) · Count bijections M→N

  1. If m≠n, no bijection exists, so the count is 0.

  2. If m=n, list the m inputs in any fixed order. The first image has m choices, the next m−1, and so on to 1.

  3. The product is m!, including 0!=1 for the empty sets.

    #{bijective maps M→N} = m! when m = n, otherwise 0

2b(iii): Count injective maps M→N

Try first: an injection assigns distinct targets to inputs, so there are fewer choices at each step.

Attempted it? Open the worked steps

2b(iii) · Count injective maps M→N

  1. If m>n, the pigeonhole principle makes an injection impossible; the count is 0.

  2. For m≤n, order the inputs. Choose distinct images in sequence: n choices, then n−1, down to n−m+1.

  3. Therefore the count is n(n−1)…(n−m+1)=n!/(n−m)!. For m=0 this is 1.

    #{injective maps M→N} = n!(n − m)! when m ≤ n, otherwise 0

2b(iv): Count surjective maps M→N

Try first: exclude maps whose image misses at least one target, correcting for maps that miss several targets.

Attempted it? Open the worked steps

2b(iv) · Count surjective maps M→N

  1. Start with all nm maps. For a chosen set of j target elements forbidden from the image, the remaining n−j targets give (n−j)m maps.

  2. There are C(n,j) ways to choose those j omitted targets. Inclusion–exclusion alternates the correction by the number omitted.

  3. The number of onto maps is ∑j=0n(−1)j C(n,j)(n−j)m. This includes the empty-set cases when interpreted with the usual combinatorial convention.

    #{onto maps M→N} = ∑j=0n(−1)j C(n, j)(n − j)m

Exercise 4.3: Elementary functions

Addition formulas for sine and cosine imply the circle identity and double-angle relation.

Connected topic: Elementary functions and inverse functions (§3.5).

3a: Prove the circle equation

Try first: expand cos(x−x) using the cosine addition theorem.

Attempted it? Open the worked steps

3a · Prove the circle equation

  1. The cosine difference formula is cos(a−b)=cos a cos b+sin a sin b.

  2. Set a=b=x. The left side is cos 0=1, and the right side is cos2x+sin2x.

  3. Hence cos2x+sin2x=1 for every real x.

    cos2x + sin2x = 1

3b: Prove the cosine double-angle identity

Try first: use cos(2x)=cos(x+x), then replace cos2x by 1−sin2x.

Attempted it? Open the worked steps

3b · Prove the cosine double-angle identity

  1. The addition formula gives cos(x+x)=cos2x−sin2x.

  2. Using cos2x=1−sin2x from the circle equation, cos(2x)=1−sin2x−sin2x=1−2sin2x.

    cos(2x) = 1 − 2sin2x

3c: Evaluate cos(arcsin x)

Try first: let θ=arcsin x, so sin θ=x and θ lies in the principal interval where cosine is non-negative.

Attempted it? Open the worked steps

3c · Evaluate cos(arcsin x)

  1. By definition, θ=arcsin x means sin θ=x, with θ∈[−π/2,π/2].

  2. The circle identity gives cos2θ=1−sin2θ=1−x2. On this interval cos θ≥0, so take the non-negative square root.

  3. Therefore cos(arcsin x)=√1 − x2, valid for −1≤x≤1.

    cos(arcsin x) = √1 − x2, for −1 ≤ x ≤ 1

3d: Find cos(π/5) exactly

Try first: use π/5=2(π/10) in the double-angle identity, then select the positive root because π/5 is in the first quadrant.

Attempted it? Open the worked steps

3d · Find cos(π/5) exactly

  1. The given value is sin(π/10)=(√5−1)/4. Its square is (3−√5)/8.

  2. Apply cos(2x)=1−2sin2x with x=π/10: cos(π/5)=1−2(3−√5)/8=(1+√5)/4.

  3. The result is positive, as expected for π/5∈(0,π/2).

    cos(π/5) = 1 + √54

Self-Study 4.4: Maps

Vertex form reveals the range and the restriction needed for a quadratic to become one-to-one.

Connected topic: Injectivity and inverses (§3.2), composition and domains (§3.4) and elementary functions (§3.5).

4a: Classify f, g, and h; modify f and g

Try first: complete the square for f, solve g for its input, and inspect the coordinate relation defining h.

Attempted it? Open the worked steps

4a · Classify f, g, and h; modify f and g

  1. For f(x)=−x2+6x−5, complete the square: f(x)=−(x−3)2+4. Its range is (−∞,4]; it is not injective on ℝ because points equally spaced about 3 have equal values.

  2. Restrict f to [3,∞) and use codomain (−∞,4]. It is then strictly decreasing and onto that codomain. Solving y=4−(x−3)2 on this branch gives f−1(y)=3+√4 − y, y≤4.

  3. For g(x)=1/(1+x), x≥0, the values are (0,1]. It is strictly decreasing and injective, but not onto ℝ. With codomain (0,1], it is bijective; solving y=1/(1+x) gives g−1(y)=1/y−1.

  4. For h(x,y)=(x,x+y,y), equality of outputs gives equality of the first and third coordinates, hence x and y agree: h is injective. Its image is the plane {(a,b,c):b=a+c}, so it is not onto ℝ3 and is not bijective.

    f(x) = −(x − 3)2 + 4

    f−1(y) = 3 + √4 − y

  5. g−1(y) = 1y − 1

4b(i): Form f∘e

Try first: since e(x)=ex is always positive, substitute it into f and use the range of the downward parabola.

Attempted it? Open the worked steps

4b(i) · Form f∘e

  1. Every real x is allowed: ex∈ℝ, the domain of f.

  2. (f∘e)(x)=−(ex)2+6ex−5=−e2x+6ex−5.

  3. Writing t=ex>0 gives 4−(t−3)2. Its maximum 4 occurs when t=3; as t→0+ or t→∞ the value tends without bound downward. The range is (−∞,4].

    (f∘e)(x) = −e2x + 6ex − 5, range (−∞, 4]

4b(ii): Form g∘f

Try first: the inner output must satisfy f(x)≥0 because g accepts only non-negative inputs.

Attempted it? Open the worked steps

4b(ii) · Form g∘f

  1. Require 4−(x−3)2≥0, so (x−3)2≤4 and 1≤x≤5. This is the composite domain.

  2. On it, f(x) ranges over [0,4], and (g∘f)(x)=1/(1+f(x))=1/[5−(x−3)2].

  3. The denominator runs from 1 to 5; reciprocation reverses the order. The range is [1/5,1].

    (g∘f)(x) = 15 − (x − 3)2, domain [1, 5], range [15, 1]

4b(iii): Form g∘e

Try first: check the exponential output against g’s non-negative domain.

Attempted it? Open the worked steps

4b(iii) · Form g∘e

  1. For all x∈ℝ, ex>0, so the composition is defined everywhere.

  2. (g∘e)(x)=1/(1+ex).

  3. As ex ranges over (0,∞), this expression decreases through (0,1). It approaches 1 and 0 but reaches neither, so the range is (0,1).

    (g∘e)(x) = 11 + ex, range (0, 1)

4b(iv): Form g∘g

Try first: the first g maps [0,∞) into (0,1], which is contained in the domain [0,∞) of the second g.

Attempted it? Open the worked steps

4b(iv) · Form g∘g

  1. The composite domain is [0,∞), since g(x)≥0 for every allowed x.

  2. (g∘g)(x)=1/[1+1/(1+x)]=(1+x)/(2+x).

  3. This increases from 1/2 at x=0 and approaches 1 without reaching it. The range is [1/2,1).

    (g∘g)(x) = 1 + x2 + x, range [12, 1)

Self-Study 4.5: Maps

Use the definitions directly: equality of composite values, existence of preimages, and the order of quantifiers.

Connected topic: Injectivity and surjectivity (§3.2).

5i: If g∘f is injective, show f is injective

Try first: assume f sends two inputs to the same value, then apply g.

Attempted it? Open the worked steps

5i · If g∘f is injective, show f is injective

  1. Suppose f(x1)=f(x2). Applying g gives (g∘f)(x1)=(g∘f)(x2).

  2. Injectivity of g∘f implies x1=x2. Thus f is injective.

    g∘f injective ⇒ f injective

5ii: If g∘f is surjective, show g is surjective

Try first: take an arbitrary element of Z and use surjectivity of the composite to produce a preimage.

Attempted it? Open the worked steps

5ii · If g∘f is surjective, show g is surjective

  1. Let z∈Z. Since g∘f is onto Z, some x∈X satisfies g(f(x))=z.

  2. The element y=f(x) belongs to Y and g(y)=z. Every z has a preimage under g, so g is surjective.

    g∘f surjective ⇒ g surjective

5iii: If f and g are surjective, show g∘f is surjective

Try first: for each target z, first choose a g-preimage y, then choose an f-preimage x of y.

Attempted it? Open the worked steps

5iii · If f and g are surjective, show g∘f is surjective

  1. Let z∈Z. Surjectivity of g gives y∈Y with g(y)=z.

  2. Surjectivity of f gives x∈X with f(x)=y. Therefore g(f(x))=z.

  3. Every z is reached by g∘f, proving surjectivity.

    f and g surjective ⇒ g∘f surjective

5iv: Give an injective composite with non-injective g

Try first: make the domain of f a singleton, while g identifies two different middle elements.

Attempted it? Open the worked steps

5iv · Give an injective composite with non-injective g

  1. Let X={a}, Y={0,1}, Z={z}. Define f(a)=0 and define g(0)=g(1)=z.

  2. The map g is not injective because 0≠1 but g(0)=g(1).

  3. The composite X→Z sends the only input a to z. A map on a singleton is injective, so g∘f is injective.

    X = {a}, Y = {0, 1}, Z = {z}

    f(a) = 0, g(0) = g(1) = z

Self-Study 4.6: Elementary functions

Factor the quartic as a quadratic in x2. For the parameterized quadratic, use the discriminant and include degenerate cases.

Connected topic: Polynomials and elementary functions (§3.5).

6a: Find and factor the roots

Try first: set u=x2 for the quartic, then split the parameter cases for ga.

Attempted it? Open the worked steps

6a · Find and factor the roots

  1. For f, divide by 5 and set u = x2: u2 + 4u − 5 = (u − 1)(u + 5). Thus f(x) = 5(x2 − 1)(x2 + 5).

  2. The factor x2 − 1 gives the real roots x = ±1; x2 + 5 is always positive, and over ℂ it has the roots ±i√5. The complete linear factorisation is

    f(x) = 5(x − 1)(x + 1)(x − i√5)(x + i√5)

  3. For ga(x) = ax2 + 2x + 1: if a = 0 it is the line 2x + 1, with the single root −1/2. If a ≠ 0, the discriminant decides:

    Δ = 22 − 4a = 4(1 − a)

  4. When a < 1 and a ≠ 0, Δ > 0 and there are two distinct real roots, so ga = a(x − r+)(x − r−) with

    r± = −1 ± √1 − aa

    At a = 1, Δ = 0 and ga = (x + 1)2, a double root at −1.

  5. When a > 1, Δ < 0: there are no real roots, and over ℂ the same factorisation holds with r± = (−1 ± i√a − 1)/a.

  6. Number of real roots of ga: two for a < 1 with a ≠ 0; one for a = 0 (a line) and for a = 1 (a double root); none for a > 1.

6b: Show cos(3x) is not generally 3cos x

Try first: A single convenient counterexample disproves a universal equality; then derive the general expression.

Attempted it? Open the worked steps

6b · Show cos(3x) is not generally 3cos x

  1. Take x=0: cos(3·0)=1 while 3cos 0=3, so they are not equal in general.

  2. Use cos(2x+x)=cos(2x)cos x−sin(2x)sin x. Substitute cos2x=cos2x−sin2x and sin2x=2sin x cos x.

  3. This gives cos3x=cos3x−3sin2x cos x=cos3x−3(1−cos2x)cos x=4cos3x−3cos x.

    cos(3x) = 4cos3x − 3cos x

Self-Study 4.7: Strictly monotone functions

Strict monotonicity forbids equal outputs at distinct inputs; injectivity alone does not require order preservation.

Connected topic: Injectivity and inverse functions (§3.2).

7a: Increasing implies injective

Try first: for two distinct inputs, order them and apply the strict inequality.

Attempted it? Open the worked steps

7a · Increasing implies injective

  1. Take x≠y. Either x<y or y<x. If x<y, strict increase gives f(x)<f(y), hence f(x)≠f(y).

  2. If y<x, strict increase gives f(y)<f(x), again unequal outputs. Therefore f is injective.

    x < y ⇒ f(x) < f(y) ⇒ f(x) ≠ f(y)

7b: Decreasing implies injective

Try first: repeat the order argument with inequalities reversed.

Attempted it? Open the worked steps

7b · Decreasing implies injective

  1. Take x≠y. If x<y, strict decrease gives f(x)>f(y); if y<x, it gives f(y)>f(x).

  2. In either case the outputs differ, so f is injective.

    x < y ⇒ f(x) > f(y) ⇒ f(x) ≠ f(y)

7c: Is every injection strictly monotone?

Try first: find an injective rearrangement of the real line that reverses order for one pair.

Attempted it? Open the worked steps

7c · Is every injection strictly monotone?

  1. Define f:ℝ→ℝ by swapping 0 and 1 and leaving every other real number fixed. This is a bijection, hence injective.

  2. Since 0<1/2 but f(0)=1>f(1/2)=1/2, it is not increasing. Since 1/2<1 but f(1/2)=1/2>f(1)=0, it is not decreasing.

  3. Thus injectivity does not imply strict monotonicity.

    f(0) = 1 > 1/2 = f(1/2)

    f(1/2) = 1/2 > 0 = f(1)

7d: Conclude that exp has an inverse

Try first: combine strict increase with the known range of the exponential.

Attempted it? Open the worked steps

7d · Conclude that exp has an inverse

  1. The exponential is strictly increasing on ℝ, so by part (a) it is injective.

  2. Its range is (0,∞), so exp:ℝ→(0,∞) is also surjective.

  3. It is therefore bijective and has an inverse, the natural logarithm ln:(0,∞)→ℝ.

    exp:ℝ→(0, ∞) is bijective, exp−1 = ln

Self-Study 4.8: Tangent addition theorems

Divide the sine and cosine addition identities only when the stated cosines are nonzero.

Connected topic: Trigonometric functions (§3.5).

8a: Prove the tangent addition and subtraction formulas

Try first: write tan(x±y)=sin(x±y)/cos(x±y), then divide numerator and denominator by cos x cos y.

Attempted it? Open the worked steps

8a · Prove the tangent addition and subtraction formulas

  1. The addition identities give sin(x±y)=sin x cos y±cos x sin y and cos(x±y)=cos x cos y∓sin x sin y.

  2. The hypotheses ensure cos x, cos y, and cos(x±y) are nonzero, so division is valid. Divide top and bottom by cos x cos y.

  3. The result is tan(x±y)=(tan x±tan y)/(1∓tan x tan y). For the plus case use matching upper/lower signs; for the minus case use opposite signs.

    tan(x ± y) = tan x ± tan y1 ∓ tan x tan y

8b: Derive the tangent double-angle formula

Try first: set y=x in the addition formula, observing the stated conditions keep the tangent defined.

Attempted it? Open the worked steps

8b · Derive the tangent double-angle formula

  1. Use tan(x+x)=(tan x+tan x)/(1−tan2x).

  2. Thus tan(2x)=2tan x/(1−tan2x), whenever x and 2x avoid the excluded tangent poles.

    tan(2x) = 2 tan x1 − tan2x

8c: Compute tan(π/12) exactly

Try first: apply the subtraction formula to π/3−π/4 and simplify by rationalizing.

Attempted it? Open the worked steps

8c · Compute tan(π/12) exactly

  1. Use tan(π/3)=√3 and tan(π/4)=1. Then tan(π/12)=(√3−1)/(1+√3).

  2. Multiply numerator and denominator by √3−1: the denominator becomes 3−1=2 and the numerator becomes (√3−1)2=4−2√3.

  3. Therefore tan(π/12)=2−√3, a positive value as expected for an angle of 15°.

    tan(π/12) = 2 − √3

Challenge 4.A: Surjective maps

Let s(k) count maps onto a fixed k-element set. Partition all maps according to their image, then invert the resulting triangular relation.

Connected topics: Map types (§3.2), binomial coefficients and finite sums (§2.4) and induction (§2.5).

4.A setup: Interpret s(k) and the target

Try first: relate surjectivity to the size of the image, and identify s(n) with the desired count.

Attempted it? Open the worked steps

4.A setup · Interpret s(k) and the target

  1. For a fixed k-element set A, s(k) is the number of maps f:M→A whose image is all of A.

  2. A map M→N is surjective exactly when its image has n elements, so s(n) counts the onto maps from M to N.

  3. Assume m=|M|≥1 for the stated Step 1 recurrence. If m=0, there is one onto map when n=0 and none when n>0; that case is separate from this recurrence.

    f is onto ⇔ |f(M)| = |N| = n

4.A Step 1: Derive the recurrence for s(k)

Try first: partition the km maps by their exact image size j and solve for the j=k term.

Attempted it? Open the worked steps

4.A Step 1 · Derive the recurrence for s(k)

  1. There are km total maps M→A. If the image has size j, first choose its j-element image B in C(k,j) ways, then choose a map onto B in s(j) ways.

  2. Summing over image sizes gives km=∑j=1k C(k,j)s(j). There is no empty image because m≥1.

  3. The j=k term is s(k), since C(k,k)=1. Rearranging gives s(k)=km−∑j=1k−1 C(k,j)s(j).

    km = ∑j=1k C(k, j)s(j)

    s(k) = km − ∑j=1k−1 C(k, j)s(j)

4.A Step 2: Check the proposed formula for k=1, 2, and 3

Try first: use the recurrence to calculate the first values and compare them with the binomial sum.

Attempted it? Open the worked steps

4.A Step 2 · Check the proposed formula for k=1, 2, and 3

  1. For k=1, s(1)=1m=1. The proposed sum is C(1,1)1m=1.

  2. For k=2, s(2)=2m−2s(1)=2m−2. The guess gives C(2,1)(−1)11m+C(2,2)2m=2m−2.

  3. For k=3, s(3)=3m−3s(1)−3s(2)=3m−3·2m+3. The guess gives the same alternating expression. These cases support, but do not prove, s(k)=∑j=1k C(k,j)(−1)k−jjm.

    s(1) = 1

    s(2) = 2m − 2

    s(3) = 3m − 3 · 2m + 3

4.A Step 3a: Reverse the order of a triangular sum

Try first: list the index region rather than manipulating terms.

Attempted it? Open the worked steps

4.A Step 3a · Reverse the order of a triangular sum

  1. The left-hand iterated sum first chooses j=1,…,k, then i=1,…,j. Its index pairs are exactly {(i,j):1≤i≤j≤k}.

  2. If instead i is fixed first, i ranges from 1 to k and j ranges from i to k. Thus ∑j=1k∑i=1j(…) = ∑i=1k∑j=ik(…).

  3. Both sides add the same term once for every pair in that finite triangular region.

    ∑j=1k∑i=1j(…) = ∑i=1k∑j=ik(…)

4.A Step 3b: Prove the binomial coefficient identity

Try first: write both sides using factorial definitions.

Attempted it? Open the worked steps

4.A Step 3b · Prove the binomial coefficient identity

  1. For 0≤i≤j≤k, C(k,j)C(j,i)=k!/[j!(k−j)!]·j!/[i!(j−i)!].

  2. Cancel j! to get k!/[i!(j−i)!(k−j)!].

  3. On the other hand, C(k,i)C(k−i,j−i)=k!/[i!(k−i)!]·(k−i)!/[(j−i)!(k−j)!], the same expression.

    C(k, j)C(j, i) = C(k, i)C(k − i, j − i)

4.A Step 3c: Establish the convolution identity

Try first: after changing order, the coefficient of each i contains a complete alternating binomial sum.

Attempted it? Open the worked steps

4.A Step 3c · Establish the convolution identity

  1. Start with ∑j=1k C(k,j)g(j) and insert g(j)=∑i=1j C(j,i)(−1)j−i im.

  2. Use Step 3a to reverse the order, then Step 3b: C(k,j)C(j,i)=C(k,i)C(k−i,j−i).

  3. The result is ∑i=1k C(k,i)im ∑j=ik C(k−i,j−i)(−1)j−i. Put r=j−i. The inner sum is ∑r=0k−i C(k−i,r)(−1)r=(1−1)k−i.

4.A Step 4 · Prove s(k)=g(k) by induction

  1. For k=1, s(1)=1 and g(1)=C(1,1)(−1)01m=1.

  2. Assume s(j)=g(j) for every 1≤j<k. The recurrence gives s(k)=km−∑j=1k−1 C(k,j)s(j).

  3. The convolution identity says km=∑j=1k C(k,j)g(j), so isolating its final term gives g(k)=km−∑j=1k−1 C(k,j)g(j).

  4. The induction hypothesis makes these right sides equal, hence s(k)=g(k). This proves the formula for every k≥1.
