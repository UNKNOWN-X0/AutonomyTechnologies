1.1 Foundations: one structure, several views

A Boolean algebra packages truth operations into a system of equations. The same structure can also be understood through order, sets, or arithmetic modulo two.

Operations and axioms

Write the structure as (B, +, ·, ', 0, 1). Join (+) and meet (·) are binary operations; complement (') is unary. The Huntington-style axioms used in the lecture state commutativity, associativity, distributivity, identities, and complements.

Core axiomsx + y = y + x(x + y) + z = x + (y + z)x·(y + z) = x·y + x·zx + 0 = xx·1 = xx + x' = 1x·x' = 0The lecture’s axiom list also states the dual commutative and associative laws for meet. Other familiar laws can be derived.

Duality swaps + with · and 0 with 1. Every equation derivable from the axioms has a derivable dual; for example, x + x = x has dual x·x = x. A distributive complemented bounded lattice is the same structure in order language: join and meet have bottom 0 and top 1, and each element has a complement.

Worked proof · complements are unique

Suppose y behaves like a complement of x: x+y=1 and x·y=0. Show y=x'.

  1. Use the identity and complement of x: y=y·1=y·(x+x').
  2. Distribute: y=(y·x)+(y·x')=0+(y·x')=y·x'.
  3. Similarly x'=x'·1=x'·(x+y)=x'·y. Therefore y=y·x'=x'·y=x'. §1.1

The proof relies on the stated complement conditions; it does not assume uniqueness in advance.

Sets, rings, and maps

The power set P(U), with union as +, intersection as ·, set complement as ', empty set as 0, and U as 1, is a Boolean algebra. There is also a ring view: XOR is addition, AND is multiplication, and every element is idempotent under multiplication.

Boolean ring translationx XOR y = (x·y') + (x'·y)x ⊙ y = x·yx ∧ y = xyx ∨ y = x + y + xy¬x = 1 + xx² = xx + x = 0The power-set example uses symmetric difference for ring addition and intersection for multiplication.

A homomorphism preserves the operations and constants. Its image is a subalgebra; when it is onto, the lecture’s isomorphism theorem identifies the quotient by its kernel with the target algebra.

Trap: duality is a rule for transforming a proved equation; it does not mean complement every variable or reverse every term.

1.2 Core identities and proof tools

Axioms are the starting point; identities are reusable consequences. Proofs become shorter when you name the law that justifies each step.

LawIdentity
De Morgan(x+y)'=x'·y'
(x·y)'=x'+y'
Absorptionx+x·y=x
x·(x+y)=x
Consensusx·y+x'·z+y·z=x·y+x'·z
Shannon expansionf=x·fx=1+x'·fx=0

De Morgan’s law follows because x'·y' is the complement of x+y: their join is 1 and their meet is 0. The uniqueness-of-complements result from §1.1 then identifies it as (x+y)'. The second law follows by duality.

Worked simplification · remove a redundant condition

Simplify x+x·y using only laws from the lecture.

  1. Factor x with distributivity: x·1+x·y=x·(1+y).
  2. Since 1+y=1, this becomes x·1.
  3. Use the identity law: x·1=x. Therefore x+x·y=x. §1.2

Read the result as: once x is already included, the stricter case x and y adds no new true assignments.

Splitting a function into cases

The cofactor fx=1 fixes x to 1; fx=0 fixes it to 0. Shannon expansion inserts x+x'=1 and distributes f across the two cases. The Boolean difference is the XOR of the cofactors, so it is 1 exactly where changing x changes the output.

Difference and quantificationD_x f = fx=1 XOR fx=0D_x(fg) = f·D_xg XOR g·D_xf XOR D_xf·D_xg(∃x)f = fx=1 + fx=0(∀x)f = fx=1·fx=0Existential quantification asks whether either case works; universal quantification asks whether both cases work. Both remove dependence on x.

Memory hook: for existential, OR the two cofactors; for universal, AND them. Check the question’s quantifier before simplifying.

Check these answers
  1. Show x'·y' has join 1 and meet 0 with x+y; it is therefore the unique complement of x+y. §1.2

1.3 Completeness, normal forms, and minimization

A representation tells you how to build a function. Completeness says whether a chosen set of connectives can represent every function; minimization asks how small a representation can be.

Build every function from a small gate set

A connective set is functionally complete if it can express every Boolean function. NAND alone is complete because it can express NOT, AND, and OR. NOR alone is complete by the dual argument.

NAND constructionx ↑ y = (x·y)'¬x = x ↑ xx·y = (x ↑ y) ↑ (x ↑ y)x+y = (x ↑ x) ↑ (y ↑ y)Once NOT, AND, and OR are available, any formula built from those connectives can be expressed with NAND.

Post’s lattice classifies families of Boolean functions closed under composition. The lecture also contrasts monotone functions, which preserve order, with affine functions, which are parity expressions over F2; a function that is both monotone and affine is constant.

Write and minimize formulas

Every Boolean function has a disjunctive normal form (OR of minterms for true rows) and a conjunctive normal form (AND of maxterms that exclude false rows). These forms are systematic, though a minimum exact two-level DNF or CNF search is NP-complete, so practical methods use structure and heuristics.

Worked example · XOR as DNF and CNF

Let f(A,B)=1 on rows 01 and 10, and 0 on rows 00 and 11.

  1. For the true rows, the minterms are A'B and AB', so the DNF is A'B+AB'.
  2. The false rows 00 and 11 give maxterms (A+B) and (A'+B'), so the CNF is (A+B)(A'+B').
  3. Both forms describe XOR: the output is 1 exactly when the inputs differ. §1.3

Quine–McCluskey combines minterms that differ in one literal, repeats until prime implicants remain, then selects a cover. Its steps preserve coverage: every combined implicant covers only true assignments, and every listed true minterm remains covered.

Trap: a complete gate set guarantees expressiveness, not a small or fast circuit.

Recall check · answer without looking

  1. How does NAND express NOT, AND, and OR?

Check these answers
  1. NOT x=x↑x; AND x·y=(x↑y)↑(x↑y); OR x+y=(x↑x)↑(y↑y). §1.3
  2. DNF ORs minterms for true rows. Exact minimum two-level minimization is NP-complete, so structured methods and heuristics matter. §1.3

1.4 Karnaugh maps remove changing variables

A K-map lays truth-table rows out so neighboring cells differ in one variable. Grouping adjacent 1s makes that changing variable disappear from the corresponding implicant.

For n variables, a map has 2n cells in Gray-code order. A legal group contains 2k adjacent cells, with wraparound adjacency allowed. Each grouped variable that changes across the group is eliminated; the implicant keeps n−k literals. Use don’t-care rows as either 0 or 1 when that makes a useful group.

K-map group ruleMap size: 2n cellsGroup size: 2k cellsRemaining literals: n−kCover every required 1 at least once. Do not include a required 0. A don’t-care can be included or ignored.

Worked example · simplify using an explicit bit order

Use variable order A,B,C with A as the most significant bit. Suppose f=1 for minterms 2, 3, 6, and 7.

  1. These rows are 010, 011, 110, and 111, so B=1 in every true row.
  2. On the map, they form a group of four. A and C vary; B stays fixed.
  3. The group leaves one literal: f=B. Verify that B=0 rows map to 0 and B=1 rows map to 1. §1.4

Trap: write the variable bit order beside minterm indices. A minterm number has no meaning without a variable order.

Recall check · answer without looking

  1. How many literals remain after grouping 8 cells on a 5-variable map?
  2. What is the safe way to use a don’t-care cell?
Check these answers
  1. Five minus three changing variables leaves two literals. §1.4
  2. Choose 0 or 1 if useful, but never use a don’t-care to cover a required zero. §1.4

1.5 Shannon views, OBDDs, and algebraic normal form

Shannon expansion recursively splits a function into simpler cases. Reusing the same split structure leads to decision diagrams; a different basis expresses the function as parity over F2.

Shannon expansionf = x·fx=1 + x'·fx=0The selected input x chooses between the two cofactors, like a 2-to-1 multiplexer.

Worked example · expand on A

For f(A,B)=A·B+A', compute the two cofactors and reconstruct f.

  1. Set A=1: fA=1=B+0=B. Set A=0: fA=0=0+1=1.
  2. Substitute: f=A·B+A'·1.
  3. The expansion matches the starting expression and separates the A=1 and A=0 cases. §1.5

An ordered binary decision diagram (OBDD) applies Shannon expansion in a fixed variable order. Reduction merges isomorphic subgraphs and removes tests whose two branches are identical. For one fixed order, the reduced OBDD is unique; a different variable order can produce a different diagram size.

The algebraic normal form (ANF) writes f as XORs of monomials over F2. Every Boolean function has a unique ANF; its coefficients can be computed by a Möbius transform. Uniqueness follows because the monomials form a basis for all truth functions on n variables. Unlike DNF, ANF uses XOR as its addition operation.

ANF shapef is the XOR of aS·∏i∈Sxi over S⊆[n]Each coefficient aS is 0 or 1. The empty product is 1; the XOR collects the selected monomials.

Trap: an OBDD is only canonical after you fix the variable order.

Recall check · answer without looking

  1. How does a Shannon expansion combine its two cofactors?
  2. What conditions make an OBDD reduced and canonical?
Check these answers
  1. Multiply the x=1 cofactor by x, the x=0 cofactor by x', then OR the two cases. §1.5
  2. Fix a variable order, merge isomorphic subgraphs, and remove redundant tests; uniqueness is for that fixed order. §1.5

1.6 Verification, hazards, and wrap-up

Equivalent formulas can behave differently while a real circuit switches. Verification must check both the Boolean function and, where needed, the physical transitions.

Static-1 hazards

Consensus relationxy + x'z + yz = xy + x'zThe term yz is logically redundant but can preserve coverage during a circuit transition.

A static-1 hazard occurs when the output should stay 1 for a small input change but a particular two-level sum-of-products implementation briefly drops to 0 because its paths have different delays. If two product terms hand off across one changing literal, their consensus term supplies overlapping coverage.

Worked example · add the consensus term

For f=xy+x'z, the consensus term is yz.

  1. The terms xy and x'z differ on x; both can be 1 at the boundary when y=z=1.
  2. Add yz. The consensus theorem gives xy+x'z+yz=xy+x'z, so the Boolean function is unchanged.
  3. In a two-level sum-of-products implementation, yz keeps the output covered during the handoff and removes the static-1 hazard described in the lecture. §1.6

Soundness and completeness

Equational reasoning is sound when every derived equation is valid in every Boolean algebra model. It is complete for tautological equivalence when every such equivalence can be derived using the calculus. The lecture’s wrap-up ties this proof view to the alternate ring, set, map, and decision-diagram representations. Its further-reading slide points to Stone on representation, Post on completeness, and Bryant on decision diagrams.

Sign check: Boolean equivalence says outputs agree for stable inputs; it does not guarantee zero propagation delay in hardware.

Recall check · answer without looking

  1. Why can a redundant consensus term help a physical circuit?
  2. What is the difference between soundness and completeness?
Check these answers
  1. It preserves overlapping coverage while unequal path delays could otherwise create a brief 1-to-0 glitch. §1.6
  2. Soundness means every proved equation is valid. Completeness means every tautological equivalence is derivable. §1.6

Explain it

Answer each “why” or “when” in your own words before opening the model response.

  1. Why does duality save proof work?
  2. Why is uniqueness of complements useful for proving De Morgan’s law?
  3. When is an apparently shorter Boolean expression unsafe to use as a circuit simplification?
  4. Why can NAND alone express every Boolean function?
  5. When should a don’t-care be included in a K-map group?
  6. Why does an OBDD’s variable order matter even when its reduced form is canonical?
  7. Why does a K-map group eliminate the variables that change?
Show model explanations
  1. The duality principle preserves derivability when + and ·, and 0 and 1, are exchanged. Once one equation is proved, its dual follows from the same axiom system without repeating the argument.
  2. It is enough to verify that the proposed expression has join 1 and meet 0 with the original expression. Those two properties make it a complement, and uniqueness identifies it with the negation.
  3. Logical equivalence alone does not account for unequal propagation delays. A two-level sum-of-products implementation may glitch during a transition, so a consensus term can be needed even when it is algebraically redundant.
  4. NAND can produce NOT by tying its inputs together. It can then produce AND and OR, and those connectives can express every Boolean function.
  5. Include it when it helps make a larger legal group and removes literals. Ignore it when it does not help; it is not a required 1 and must never force a group through a required 0.
  6. Canonicity holds for a fixed order. Changing the order changes the sequence of Shannon splits and can therefore change the reduced diagram’s shape and size.
  7. The group contains every combination of the changing variables while the remaining variables stay fixed. Combining those cases with Boolean identities removes the changing literals, leaving only the fixed ones.

Exam-style problems

Allow about 20 minutes per problem. Show each identity used and check your final expression against the truth conditions.

1 · Prove, represent, and implement

For f(A,B,C)=A'B+AB'C, use the Boolean algebra and representation ideas from §§1.1–1.3.

  1. Use Shannon expansion on A to write the two cofactors and reconstruct f.
  2. Write a NAND-only implementation for each product term and the outer OR, using NAND as the only gate.
  3. State whether the given expression is a DNF and explain how you would verify equivalence to your NAND version.
Show the worked answer
  1. For A=1, f=B'C; for A=0, f=B. Therefore f=A·(B'C)+A'·B, the original function after reordering its terms. §1.2 §1.5
  2. Make complements with x'=x↑x. For p=A'B, compute u=A'↑B=(A'B)', then p=u↑u. For q=AB'C, compute v=A↑B'=(AB')', r=v↑v=AB', s=r↑C=(AB'C)', then q=s↑s. Finally f=(p↑p)↑(q↑q), which is p OR q by De Morgan. §1.3
  3. Yes: it is an OR of product terms. A truth table or algebraic rewriting can show that the gate expression produces the same value on every assignment. §1.3

2 · Minimize, then check a circuit transition

Let f(A,B,C)=1 for minterms 2,3,6,7 and 0 elsewhere. Use A,B,C as the bit order with A most significant.

  1. Group the true cells on a 3-variable K-map and derive the minimal expression.
  2. Expand your result on A using Shannon’s theorem.
  3. Explain what a static-1 hazard is and when the consensus theorem helps with it.
Show the worked answer
  1. The rows 010, 011, 110, and 111 all have B=1; they form a group of four. A and C vary, so f=B. §1.4
  2. B is independent of A, so both A cofactors equal B. Shannon gives f=AB+A'B=B(A+A')=B. §1.2 §1.5
  3. A static-1 hazard is a brief drop to 0 when the intended output stays 1 during a small input change. In a two-level sum-of-products implementation, an added consensus term can maintain overlapping coverage without changing the Boolean function. §1.6
