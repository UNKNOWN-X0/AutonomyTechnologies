Task 4: Test whether a number is even

Connected topic: Computers, programs, and data representation (Chapter 2)

Task 04 · is_even(number)

Try first: use the remainder after division by two.

Attempted it? Open the worked steps

Task 04 · is_even(number) · worked solution

  1. An integer is even exactly when its remainder modulo 2 is zero. Python’s modulo rule also handles negative integers consistently.

  2. Return the Boolean comparison number % 2 == 0. Do not return the strings "True" or "False".

  3. Check 4 gives True, 5 gives False, and -2 gives True.

  4. Core code: the following is the key operation; fit it into the required function signature and return shape.

    def is_even(number):
    return number % 2 == 0

Task 05 · greet(name) · worked solution
