1.1 Foundations: one structure, several views

A Boolean algebra packages truth operations into a system of equations. The same structure can also be understood through order, sets, or arithmetic modulo two.

Operations and axioms

Write the structure as (B, +, ·, ', 0, 1). Join (+) and meet (·) are binary operations; complement (') is unary. The Huntington-style axioms used in the lecture state commutativity, associativity, distributivity, identities, and complements.

Core axiomsx + y = y + x(x + y) + z = x + (y + z)x·(y + z) = x·y + x·zx + y·z = (x + y)·(x + z)x + 0 = xx·1 = xx + x' = 1x·x' = 0The lecture’s axiom list also states the dual commutative and associative laws for meet. It prints only the first distributive law; the second is needed, because XOR and AND on {0,1} satisfy the printed list but not x+x=x.

Duality swaps + with · and 0 with 1. The axiom list is self-dual, so every equation derivable from the axioms has a derivable dual. For example, x + x = (x + x)·1 = (x + x)·(x + x') = x + x·x' = x uses the second distributive law, and its dual is x·x = x. A distributive complemented bounded lattice is the same structure in order language: join and meet have bottom 0 and top 1, and each element has a complement.

Worked proof · complements are unique

Suppose y behaves like a complement of x: x+y=1 and x·y=0. Show y=x'.

  1. Use the identity and complement of x: y=y·1=y·(x+x').
  2. Distribute: y=(y·x)+(y·x')=0+(y·x')=y·x'.
  3. Similarly x'=x'·1=x'·(x+y)=x'·y. Therefore y=y·x'=x'·y=x'. §1.1

The proof relies on the stated complement conditions; it does not assume uniqueness in advance.

Sets, rings, and maps

The power set P(U), with union as +, intersection as ·, set complement as ', empty set as 0, and U as 1, is a Boolean algebra. There is also a ring view: XOR is addition, AND is multiplication, and every element is idempotent under multiplication. The guide writes XOR as ⊕, because slide 13 reuses + for it.

Boolean ring translationx ⊕ y = (x·y') + (x'·y)x ⊙ y = x·yx ∧ y = xyx ∨ y = x ⊕ y ⊕ xy¬x = 1 ⊕ xx2 = xx ⊕ x = 0Slide 13 reuses + for ring addition; here ⊕ keeps it apart from join. The power-set example uses symmetric difference for ring addition and intersection for multiplication.

A homomorphism h preserves the operations and constants. Its kernel is ker h = h−1(0), and its image is a subalgebra; when it is onto, the lecture’s isomorphism theorem identifies the quotient by its kernel with the target algebra.

Trap: duality is a rule for transforming a proved equation; it does not mean complement every variable or reverse every term.

1.2 Core identities and proof tools

Axioms are the starting point; identities are reusable consequences. Proofs become shorter when you name the law that justifies each step.

Worked proof · De Morgan’s first law

Show that x'·y' is the complement of x+y.

  1. Join: (x+y)+x'y'=(x+y+x')(x+y+y')=1·1=1, by the second distributive law.
  2. Meet: (x+y)·x'y'=x·x'·y'+y·x'·y'=0+0=0, by the first distributive law.
  3. Uniqueness of complements from §1.1 gives (x+y)'=x'y'. The second law follows by duality. §1.2

Worked simplification · remove a redundant condition

Simplify x+x·y using only laws from the lecture.

  1. Factor x with distributivity: x·1+x·y=x·(1+y).
  2. Since 1+y=(y'+y)+y=y'+(y+y)=y'+y=1, using idempotence from §1.1, this becomes x·1.
  3. Use the identity law: x·1=x. Therefore x+x·y=x. §1.2

Read the result as: once x is already included, the stricter case x and y adds no new true assignments.

Splitting a function into cases

The cofactor fx=1 fixes x to 1; fx=0 fixes it to 0. The Boolean difference ∂f/∂x is the XOR of the cofactors, so it is 1 exactly where changing x changes the output.

Derivation · Shannon expansion

  1. Insert the complement law: f=f·1=f·(x+x').
  2. Distribute: f=x·f+x'·f.
  3. Where x=1 only fx=1 matters, so x·f=x·fx=1; likewise x'·f=x'·fx=0. Therefore f=x·fx=1+x'·fx=0. §1.2
Difference and quantification∂f/∂x = fx=1 ⊕ fx=0∂(f ⊕ g)/∂x = ∂f/∂x ⊕ ∂g/∂x∂(fg)/∂x = f·∂g/∂x ⊕ g·∂f/∂x ⊕ ∂f/∂x·∂g/∂x(∃x)f = fx=1 + fx=0(∀x)f = fx=1·fx=0(∀x)f ≤ f ≤ (∃x)ff does not depend on x exactly when ∂f/∂x=0. Existential quantification (smoothing) asks whether either case works; universal quantification (consensus) asks whether both cases work. Both remove dependence on x.

Worked example · difference and quantifiers

Let f=x+y.

  1. Cofactors: fx=1=1 and fx=0=y.
  2. Difference: ∂f/∂x=1⊕y=y'. Changing x matters only when y=0.
  3. Quantifiers: (∃x)f=1+y=1 and (∀x)f=1·y=y. Check: y≤x+y≤1. §1.2

Memory hook: for existential, OR the two cofactors; for universal, AND them. Check the question’s quantifier before simplifying.

1.3 Completeness, normal forms, and minimisation

A representation tells you how to build a function. Completeness says whether a chosen set of connectives can represent every function; minimisation asks how small a representation can be.

Build every function from a small gate set

A connective set is functionally complete if it can express every Boolean function. NAND alone is complete because it can express NOT, AND, and OR. NOR alone is complete by the dual argument.

NAND constructionx ↑ y = (x·y)'¬x = x ↑ xx·y = (x ↑ y) ↑ (x ↑ y)x+y = (x ↑ x) ↑ (y ↑ y)Once NOT, AND, and OR are available, any formula built from those connectives can be expressed with NAND.

Post’s lattice classifies families of Boolean functions closed under composition. The lecture also contrasts monotone functions, which preserve order, with affine functions, which are parity expressions over F2; a function that is both monotone and affine is a constant or a single variable. (The lecture says only “constant”, but f=x is a counterexample; see the slips.) Any XOR of two or more inputs falls from 1 to 0 when a second input turns on.

Write and minimise formulas

Every Boolean function has a disjunctive normal form (OR of minterms for true rows) and a conjunctive normal form (AND of maxterms that exclude false rows). These forms are systematic, though finding a minimum two-level form is hard (deciding this from a truth table is NP-complete, as the lecture states), so practical methods use structure and heuristics.

Worked example · XOR as DNF and CNF

Let f(A,B)=1 on rows 01 and 10, and 0 on rows 00 and 11.

  1. For the true rows, the minterms are A'B and AB', so the DNF is A'B+AB'.
  2. The false rows 00 and 11 give maxterms (A+B) and (A'+B'), so the CNF is (A+B)(A'+B').
  3. Both forms describe XOR: the output is 1 exactly when the inputs differ. §1.3

Quine–McCluskey combines minterms that differ in one literal, repeats until prime implicants remain, then selects a cover. Its steps preserve coverage: every combined implicant covers only true assignments, and every listed true minterm remains covered.

Worked example · Quine–McCluskey on minterms 1, 3, 5, 7

  1. Write the rows in A,B,C order: 001, 011, 101, 111.
  2. Combine pairs differing in one bit: 0−1, −01, −11, 1−1.
  3. Combine again: 0−1 with 1−1 gives −−1, and −01 with −11 gives the same cube.
  4. The only prime implicant is −−1, so f=C. Check: C is 1 on exactly the four odd rows. §1.3

Trap: a complete gate set guarantees expressiveness, not a small or fast circuit.

1.4 Karnaugh maps remove changing variables

A K-map lays truth-table rows out so neighbouring cells differ in one variable. Grouping adjacent 1s makes that changing variable disappear from the corresponding implicant.

For n variables, a map has 2n cells in Gray-code order. A legal group is a rectangle of 2k cells (possibly wrapping), so that it contains every combination of k changing variables. Each variable that changes across the group is eliminated; the implicant keeps n−k literals. Use don’t-care rows as either 0 or 1 when that makes a useful group.

K-map group ruleMap size: 2n cellsGroup size: 2k cellsRemaining literals: n−kCover every required 1 at least once. Do not include a required 0. A don’t-care can be included or ignored.

Worked example · simplify using an explicit bit order

Use variable order A,B,C with A as the most significant bit. Suppose f=1 for minterms 2, 3, 6, and 7.

  1. These rows are 010, 011, 110, and 111, so B=1 in every true row.
  2. On the map, they form a group of four. A and C vary; B stays fixed.
  3. The group leaves one literal: f=B. Verify that B=0 rows map to 0 and B=1 rows map to 1. §1.4

Trap: write the variable bit order beside minterm indices. A minterm number has no meaning without a variable order.

1.5 Shannon views, OBDDs, and algebraic normal form

Shannon expansion recursively splits a function into simpler cases. Reusing the same split structure leads to decision diagrams; a different basis expresses the function as parity over F2.

Shannon expansionf = x·fx=1 + x'·fx=0The selected input x chooses between the two cofactors, like a 2-to-1 multiplexer.

Worked example · expand on A

For f(A,B)=A·B+A', compute the two cofactors and reconstruct f.

  1. Set A=1: fA=1=B+0=B. Set A=0: fA=0=0+1=1.
  2. Substitute: f=A·B+A'·1.
  3. The expansion matches the starting expression and separates the A=1 and A=0 cases. §1.5

An ordered binary decision diagram (OBDD) applies Shannon expansion in a fixed variable order. Reduction merges isomorphic subgraphs and removes tests whose two branches are identical. For one fixed order, the reduced OBDD is unique; a different variable order can produce a different diagram size.

The algebraic normal form (ANF) writes f as XORs of monomials over F2. Every Boolean function has a unique ANF; its coefficients can be computed by a Möbius transform. Uniqueness follows because the monomials form a basis for all truth functions on n variables. Unlike DNF, ANF uses XOR as its addition operation.

Worked example · OBDD for A?B:C with order A,B,C

  1. Split on A: the 1-branch is B and the 0-branch is C.
  2. Split the B branch: B=1 gives terminal 1, B=0 gives terminal 0. The C branch is the same shape.
  3. Each test has different branches, and the B and C nodes test different variables, so nothing reduces further: 3 nonterminal nodes.
  4. Check: with order B,C,A the same function needs 5 nodes, so order matters. §1.5

Worked example · Möbius transform of NAND

Outputs for rows 00, 01, 10, 11 are 1,1,1,0, with A as the first bit.

  1. B pass: XOR each B=1 entry with its B=0 partner, giving 1,0,1,1.
  2. A pass: XOR each A=1 entry with its A=0 partner, giving 1,0,0,1.
  3. The entries are the coefficients of 1, B, A, AB, so f=1⊕AB.
  4. Check: AB=1 only on row 11, where f=0. §1.5
ANF shapef is the XOR of aS·∏i∈Sxi over S⊆[n]Each coefficient aS is 0 or 1. The empty product is 1; the XOR collects the selected monomials.

Trap: an OBDD is only canonical after you fix the variable order.

1.6 Verification, hazards, and wrap-up

Equivalent formulas can behave differently while a real circuit switches. Verification must check both the Boolean function and, where needed, the physical transitions.

Static-1 hazards

Consensus relationxy + x'z + yz = xy + x'zThe term yz is logically redundant but can preserve coverage during a circuit transition.

A static-1 hazard occurs when the output should stay 1 for a small input change but a particular two-level sum-of-products implementation briefly drops to 0 because its paths have different delays. If two product terms hand off across one changing literal, their consensus term supplies overlapping coverage, for one input changing at a time. To form it, take terms xA and x'B: the consensus is AB.

Derivation · the consensus theorem

  1. Expand: yz=yz(x+x')=xyz+x'yz.
  2. Absorb: xy+xyz=xy and x'z+x'yz=x'z.
  3. Therefore xy+x'z+yz=xy+x'z. §1.6

Worked example · add the consensus term

For f=xy+x'z, the consensus term is yz.

  1. The terms xy and x'z differ on x. When y=z=1, exactly one is 1 at each stable input, so the output should stay 1; during the change a delay can leave both at 0.
  2. Add yz. The consensus theorem gives xy+x'z+yz=xy+x'z, so the Boolean function is unchanged.
  3. In a two-level sum-of-products implementation, yz keeps the output covered during the handoff and removes the static-1 hazard described in the lecture. §1.6

Soundness and completeness

Equational reasoning is sound when every derived equation is valid in every Boolean algebra model. It is complete for tautological equivalence when every such equivalence can be derived using the calculus; that needs the full axiom list of §1.1, including the second distributive law. The lecture’s wrap-up ties this proof view to the alternate ring, set, map, and decision-diagram representations. Its further-reading slide points to Stone on representation, Post on completeness, and Bryant on decision diagrams.

Sign check: Boolean equivalence says outputs agree for stable inputs; it does not guarantee zero propagation delay in hardware.

Derive it cold

On blank paper, rebuild each chain using only earlier definitions and laws.

  1. Duality: each axiom’s dual is an axiom, so swapping symbols in a proof of x+x=x proves x·x=x. §1.1
  2. De Morgan: show x'y' complements x+y, then use uniqueness. §1.2
  3. Absorption: x+xy=x(1+y)=x. §1.2
  4. Shannon: f=f(x+x')=xf+x'f, then read each term as a cofactor. §1.2
  5. NAND completeness: derive NOT, AND, and OR, then cite functional completeness of those connectives. §1.3

  7. OBDD uniqueness: explain why the fixed order plus reduction rules determine the same graph. §1.5
  8. Consensus and hazard cover: expand yz with x+x' and show it is absorbed by xy+x'z. §1.6

Explain it

Answer each “why” or “when” in your own words before opening the model response.

  1. Why does duality save proof work?
  2. Why is uniqueness of complements useful for proving De Morgan’s law?
  3. When is an apparently shorter Boolean expression unsafe to use as a circuit simplification?
  4. Why can NAND alone express every Boolean function?
  5. When should a don’t-care be included in a K-map group?
  6. Why does an OBDD’s variable order matter even when its reduced form is canonical?

Show model explanations
  1. The duality principle preserves derivability when + and ·, and 0 and 1, are exchanged. Once one equation is proved, its dual follows from the same axiom system without repeating the argument. §1.1
  2. It is enough to verify that the proposed expression has join 1 and meet 0 with the original expression. Those two properties make it a complement, and uniqueness identifies it with the negation. §1.2
  3. Logical equivalence alone does not account for unequal propagation delays. A two-level sum-of-products implementation may glitch during a transition, so a consensus term can be needed even when it is algebraically redundant. §1.6
  4. NAND can produce NOT by tying its inputs together. It can then produce AND and OR, and those connectives can express every Boolean function. §1.3
  5. Include it when it helps make a larger legal group and removes literals. Ignore it when it does not help; it is not a required 1 and must never force a group through a required 0. §1.4
  6. Canonicity holds for a fixed order. Changing the order changes the sequence of Shannon splits and can therefore change the reduced diagram’s shape and size. §1.5
  7. The group contains every combination of the changing variables while the remaining variables stay fixed. Combining those cases with Boolean identities removes the changing literals, leaving only the fixed ones. §1.4

Exam-style problems

Allow about 20 minutes per problem. Show each identity used and check your final expression against the truth conditions.

1 · Prove, represent, and implement

For f(A,B,C)=A'B+AB'C, use Shannon expansion, NAND construction and normal forms from §§1.2, 1.3 and 1.5.

  1. Use Shannon expansion on A to write the two cofactors and reconstruct f.
  2. Write a NAND-only implementation for each product term and the outer OR, using NAND as the only gate.
  3. State whether the given expression is a DNF and explain how you would verify equivalence to your NAND version.
Show the worked answer
  1. For A=1, f=B'C; for A=0, f=B. Therefore f=A·(B'C)+A'·B, the original function after reordering its terms. §1.2 §1.5
  2. Make complements with x'=x↑x. For p=A'B, compute u=A'↑B=(A'B)', then p=u↑u. For q=AB'C, compute v=A↑B'=(AB')', r=v↑v=AB', s=r↑C=(AB'C)', then q=s↑s. Finally f=(p↑p)↑(q↑q), which is p OR q by De Morgan. §1.3
  3. Yes: it is an OR of product terms. A truth table or algebraic rewriting can show that the gate expression produces the same value on every assignment. §1.3

2 · Minimise, then check a circuit transition

Let f(A,B,C)=1 for minterms 2,3,6,7 and 0 elsewhere. Use A,B,C as the bit order with A most significant.

  1. Group the true cells on a 3-variable K-map and derive the minimal expression.
  2. Expand your result on A using Shannon’s theorem.
  3. Explain what a static-1 hazard is and when the consensus theorem helps with it.
Show the worked answer
  1. The rows 010, 011, 110, and 111 all have B=1; they form a group of four. A and C vary, so f=B. §1.4
  2. B is independent of A, so both A cofactors equal B. Shannon gives f=AB+A'B=B(A+A')=B. §1.2 §1.5
  3. A static-1 hazard is a brief drop to 0 when the intended output stays 1 during a small input change. In a two-level sum-of-products implementation, an added consensus term can maintain overlapping coverage without changing the Boolean function. §1.6

Slips in the notes

Each item was checked against the rendered slides and is listed with its slide number. The lecture’s wording is given too, so you can recognise it. Ask the lecturer which version an exam would mark.

  • Slide 6 · error, second distributive law missing: the axiom list prints only x·(y+z)=x·y+x·z, although its intuition box says distribution works both ways. XOR and AND on {0,1} satisfy every printed line, yet 1 XOR 1=0, so idempotence (slide 7), absorption’s step 1+y=1, duality and completeness (slide 45) do not follow from the list as printed. §1.1 adds x+y·z=(x+y)·(x+z). The word “minimal” is probably also too strong, since associativity is usually derivable from Huntington’s set.
  • Slides 11 and 13 · notation clash: slide 11 and most of the lecture use + for join, while slide 13 reuses + for ring addition, giving x+x=0 beside x+x=x. This guide writes ring addition as ⊕ throughout.
  • Slide 27 · error, Post’s conditions incomplete: the slide says a nonmonotone and a nonaffine operation imply completeness. The function x·y' is both, yet it preserves 0, so it cannot make NOT or 1. Post’s criterion needs five: for each of the classes 0-preserving, 1-preserving, self-dual, monotone and affine, the set must contain a function outside it. §1.3 uses only the NAND argument.
  • Slide 28 · error, monotone and affine: the slide says such a function is constant. But f(x)=x is both. The correct result is a constant or a single input variable; enumerating all 256 functions of three variables gives exactly 0, 1, x1, x2 and x3. §1.3 and practice 15 use the corrected form.
  • Slide 30 · simplification: “NP-complete” is printed without saying what the input is. This guide states the truth-table form; the problem is harder when the input is a formula rather than a table. That last remark is a standard result, not from the notes.
  • Slide 34 · wording: changing variables are said to be “eliminated by consensus”. The step that removes a variable is xA+x'A=A, which is distribution and complement, not the consensus theorem. §1.4 says “eliminated” and §1.3 shows the combining step.
  • Slide 35 · minterm order not stated: the slide gives Σm(1,3,5,7) and concludes f=B, without labelling the bit order. Under A,B,C with A most significant, that set describes C; the slide’s conclusion needs a different order. Its intuition box says A and C vary, which fits f=B, not the listed set in that order. The drawn map has no axis labels, and its two groups are separated by one column; with Gray columns, the B=1 columns would be next to each other. This guide states the convention in its worked example.
  • Slide 36 · expression conflicts with listed rows: with W,X,Y,Z in that bit order, the listed 1s {1,3,7,11,15} and don’t-cares {5,9,13} are all odd indices, and every even index is 0, so the list simplifies to f=Z when all three don’t-cares are used as 1. The printed expression YZ+X'Z+W'Z' also covers the required zeros 0, 2, 4 and 6, while YZ+X'Z alone already covers every 1. W'Z' is probably a typo for W'Z. The grid has no axis labels, and its coloured groups do not obviously match the printed terms; that reading is uncertain. This guide follows the listed rows, “1s at 1,3,7,11,15”.
  • Slide 43 · simplification: “adding consensus terms eliminates static hazards” holds when one input changes at a time and all the needed consensus terms are added. §1.6 says so.
