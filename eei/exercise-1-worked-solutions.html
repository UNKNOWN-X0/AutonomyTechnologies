Task 1: Cylinder in cylindrical coordinates

A right circular cylinder has radius a, height h, and its axis lies along z. The origin is at the centre of the base; z points upward.

1a: Describe the three boundary surfaces

Try first: write the coordinate ranges for the base, curved side, and top.

Attempted it? Open the worked steps

1a · Surface coordinates

  1. In cylindrical coordinates a point is r = ρ eρ + z ez. A disk varies in ρ and φ while holding z fixed; the side holds ρ fixed.

  2. For the base, set z = 0: 0 ≤ ρ ≤ a, 0 ≤ φ < 2π. For the top, set z = h with the same disk ranges.

  3. For the lateral surface, set ρ = a, with 0 ≤ φ < 2π and 0 ≤ z ≤ h.

    Result: base: (ρ, φ, 0); side: (a, φ, z); top: (ρ, φ, h), over the ranges above.

    Check: the curved side has no radial thickness; each disk spans the full radius.

1b: Give the outward unit normals

Try first: identify which coordinate direction points out of each smooth face.

Attempted it? Open the worked steps

1b · Outward normals

  1. The bottom face lies at z = 0. The cylinder occupies larger z, so outward points downward: −ez.

  2. The side is at fixed ρ = a; increasing ρ leaves the cylinder, so its normal is +eρ.

  3. The top is at z = h, so outward is +ez. Thus the normals are base −ez, side +eρ, top +ez. At the sharp circular rims, the adjacent face normals differ, so there is no single smooth-face normal.

    Check: each normal points away from the cylinder's interior.

Task 2: Hemisphere of radius a

Include both the curved half-sphere and its flat base when finding total surface area.

2a: Total surface area

Try first: calculate the curved part and disk separately, then add them.

Attempted it? Open the worked steps

2a · Curved surface plus base

  1. Use spherical coordinates with polar angle θ measured down from +z. On the curved hemisphere, r = a, 0 ≤ θ ≤ π/2, 0 ≤ φ < 2π, and dA = a² sin θ dθ dφ.

  2. Integrate the curved part: Acurve = ∫₀²π ∫₀^(π/2) a² sin θ dθ dφ = 2πa².

  3. The base disk has area Abase = πa². Add the two pieces: Atotal = 2πa² + πa² = 3πa².

    Check: the curved half is half the sphere's 4πa² area; remember to include the base.

2b: Volume

Try first: set the spherical radial limit to a and the polar angle to the upper half.

Attempted it? Open the worked steps

2b · Spherical volume integral

  1. For the hemisphere, 0 ≤ r ≤ a, 0 ≤ θ ≤ π/2, and 0 ≤ φ < 2π. The volume element is dV = r² sin θ dr dθ dφ.

  2. Separate the factors: V = (∫₀ᵃ r² dr)(∫₀^(π/2) sin θ dθ)(∫₀²π dφ) = (a³/3)(1)(2π).

  3. Result: V = 2πa³/3.

    Check: it is half the full sphere's 4πa³/3 volume.

Task 3: Field integral around a circle

Integrate each field around a circle of radius ρ = b centred at the origin. Assume φ increases from 0 to 2π, counterclockwise when viewed from +z. Reversing this path reverses any nonzero result.

3a: Uniform x-directed field

Given H = H0ex. Try first: parameterize the circle and evaluate the dot product.

Attempted it? Open the worked steps

3a: Uniform field

  1. On the circle, ds = b eφ dφ, where eφ = −sin φ ex + cos φ ey.

  2. Then H · ds = −b H0 sin φ dφ. Integrate around the full loop: ∮ H · ds = −b H0 ∫₀²π sin φ dφ.

  3. Result: ∮ H · ds = 0. The positive and negative tangential contributions cancel over a full turn.

    Check: the field is not perpendicular everywhere; zero comes from cancellation, not pointwise orthogonality.

3b: Radial field

Given H = H0eρ. Try first: compare the field direction with the path tangent.

Attempted it? Open the worked steps

3b: Radial field

  1. The circle's line element is tangential: ds = b eφ dφ. The field points radially along eρ.

  2. Radial and azimuthal unit vectors are perpendicular, so eρ · eφ = 0 at every point. Hence H · ds = 0 everywhere on the path.

  3. Result: ∮ H · ds = 0.

    Check: unlike 3a, this integrand vanishes point by point, so no cancellation argument is needed.

3c: Azimuthal field growing with radius

Given H = H0(ρ/a)eφ. Try first: evaluate the field on ρ = b and use the circle's tangent element.

Attempted it? Open the worked steps

3c · Tangential field

  1. On ρ = b, the field is H = (b/a)H0eφ; the path element is ds = b eφ dφ.

  2. The directions agree, so H · ds = (H0b²/a)dφ. Integrating through 2π gives 2πH0b²/a.

  3. Result: ∮ H · ds = 2πH0b²/a. The assumed counterclockwise direction makes it positive.

    Check: H has units A/m, so H times path length has units A. Clockwise traversal changes the sign.
